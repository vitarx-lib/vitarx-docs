# Effect

Effect类是VitaRx中的一个核心类，用于管理具有生命周期的副作用。它提供了完整的状态管理、生命周期控制和错误处理机制。

## 基本概念

Effect类实现了`EffectInterface`接口，主要用于处理以下场景：
- 需要清理的副作用（如事件监听、定时器等）
- 需要暂停/恢复的操作
- 需要错误处理的异步操作

## 状态管理

Effect实例有三种状态：
- `active`: 活跃状态，表示Effect正常运行
- `paused`: 暂停状态，表示Effect被临时暂停
- `deprecated`: 弃用状态，表示Effect已被销毁

## 核心API

### 状态查询

```ts
// 检查Effect状态
const effect = new Effect()

console.log(effect.isActive)     // true
console.log(effect.isPaused)     // false
console.log(effect.isDeprecated) // false
```

### 生命周期控制

```ts
import { Effect } from 'vitarx'

const effect = new Effect()

// 监听销毁事件
effect.onDestroyed(() => {
  console.log('Effect已被销毁')
})

// 暂停Effect
effect.pause()
console.log(effect.isPaused) // true

// 恢复Effect
effect.unpause()
console.log(effect.isActive) // true

// 销毁Effect
effect.destroy()
console.log(effect.isDeprecated) // true
```

### 错误处理

```ts
import { Effect } from 'vitarx'

const effect = new Effect()

// 添加错误处理器
effect.onError((error) => {
  console.error('Effect发生错误:', error)
})
```

## 最佳实践

### 1. 资源清理

```ts
import { Effect } from 'vitarx'

function createTimer() {
  const effect = new Effect()
  const timer = setInterval(() => {
    console.log('定时器执行')
  }, 1000)
  
  // 在Effect销毁时清理定时器
  effect.onDestroyed(() => {
    clearInterval(timer)
  })
  
  return effect
}

const timerEffect = createTimer()
// 不需要时销毁Effect
timerEffect.destroy()
```

### 2. 暂停/恢复功能

```ts
import { Effect } from 'vitarx'

function createDataFetcher() {
  const effect = new Effect()
  let active = true
  
  effect.onPause(() => {
    active = false
  })
  
  effect.onUnPause(() => {
    active = true
    fetchData()
  })
  
  async function fetchData() {
    while (active) {
      try {
        const data = await fetch('/api/data')
        console.log(data)
        await new Promise(resolve => setTimeout(resolve, 5000))
      } catch (error) {
        effect.reportError(error)
      }
    }
  }
  
  fetchData()
  return effect
}

const fetcher = createDataFetcher()
// 暂停数据获取
fetcher.pause()
// 恢复数据获取
fetcher.unpause()
```

### 3. 类型检查

```ts
import { isEffect } from 'vitarx'

function handleEffect(obj: unknown) {
  if (isEffect(obj)) {
    // obj被类型推断为EffectInterface
    obj.destroy()
  }
}
```

## 注意事项

1. Effect一旦被销毁（调用`destroy()`），就不能再被使用，所有操作都会抛出错误
2. 只有在`active`状态下才能调用`pause()`，只有在`paused`状态下才能调用`unpause()`
3. 建议在作用域卸载时销毁相关的Effect实例，以防止内存泄漏
4. 如果没有设置错误处理器，错误会被输出到控制台
