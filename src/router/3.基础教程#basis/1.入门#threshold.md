# 入门

Vitarx Router 是 Vitarx 官方的客户端路由解决方案。它能够在单页应用中根据 URL 来切换页面，提供流畅的用户体验。

Vitarx Router 的核心是基于 `RouteView` 组件，通过配置路由线路来告诉 Vitarx Router 在 URL 变化时应该切换到哪个页面。

:::info:学习基础
这份文档假设你已经了解了 Vitarx 的基础概念。如果你还不了解，可以先学习 [vitarx文档](/docs)。
:::

## 创建路由器实例

路由器实例可以通过助手函数 `createRouter()` 来创建。以下是一个完整的示例：

```js
// src/router/index.ts
import { createRouter } from 'vitarx-router'

// 导入路由线路配置列表
import routes from './routes'

// 创建路由器实例
const router = createRouter({
  routes,
  // 路由模式配置
  mode: 'path', // 支持：hash、path、memory 三种模式
  // 可选：路由基础路径
  base: '/app/',
  // 可选：路由切换时的滚动行为
  scrollBehavior: (to, from, savedPosition) => {
    if (savedPosition) {
      return savedPosition
    }
    return { top: 0 }
  }
})

// 导出路由器实例
export default router
```

### 路由模式说明

- **path模式**（推荐）：使用浏览器的 History API，URL 更美观，但需要服务器配置支持。
  ```
  示例：https://example.com/user/profile
  ```

- **hash模式**：使用 URL 的 hash 部分来模拟路径，无需服务器配置。
  ```
  示例：https://example.com/#/user/profile
  ```

- **memory模式**：完全基于内存的路由模式，适用于非浏览器环境。
  ```js
  // 示例：仅在内存中维护路由状态
  const router = createRouter({ mode: 'memory', routes })
  ```

## 挂载路由器实例

### 定义根组件

```jsx
// src/App.tsx
import { RouterView } from 'vitarx-router'

const AppHome = () => {
  return (
    <div>
      <nav>
        <a href="/">首页</a>
        <a href="/about">关于</a>
      </nav>
      {/* RouterView 组件用于渲染匹配的路由组件 */}
      <RouterView />
    </div>
  )
}

export default AppHome
```

### 在入口模块中挂载

```js
// src/main.ts
import { createApp } from 'vitarx'
import router from './router'
import AppHome from './App'

// 创建应用实例并挂载路由器
const app = createApp('#root').use(router)

// 渲染根组件
app.render(AppHome)
```

:::info:最佳实践
建议使用 `.use()` 方法注册路由器实例，这样可以：
1. 确保路由器正确初始化
2. 避免IDE自动清理未使用的导入
3. 保持与其他插件一致的注册方式
:::

## 访问路由器

### 方式一：直接导入

```js
// 从路由配置文件中导入
import router from './router'

// 使用路由器方法
router.push('/about')
```

### 方式二：使用助手函数

```js
import { useRouter } from 'vitarx-router'

function MyComponent() {
  const router = useRouter()
  
  const handleClick = () => {
    router.push({
      path: '/user',
      query: { id: '123' }
    })
  }
  
  return <button onClick={handleClick}>跳转到用户页面</button>
}
```

## 获取当前路由

### 使用useRoute助手函数

```js
import { useRoute } from 'vitarx-router'

function UserProfile() {
  const route = useRoute()
  
  console.log(route.path)      // 当前路径
  console.log(route.params.id) // 路由参数
  console.log(route.query)     // 查询参数
  
  return <div>用户ID：{route.params.id}</div>
}
```

## currentRouteLocation 详解

`currentRouteLocation` 是一个只读的响应式对象，包含以下属性：

```js
// 示例路由：/user/123?tab=profile#settings
const route = useRoute()

// 路由索引
console.log(route.index)     // 例如：'user'

// 路由路径
console.log(route.path)      // '/user/123'

// 完整路径（包含查询参数和hash）
console.log(route.fullPath)  // '/user/123?tab=profile#settings'

// 路由后缀
console.log(route.suffix)    // 例如：'-edit'

// 查询参数对象
console.log(route.query)     // { tab: 'profile' }

// 动态参数对象
console.log(route.params)    // { id: '123' }

// hash值
console.log(route.hash)      // '#settings'

// 路由元信息
console.log(route.meta)      // { requiresAuth: true }

// 匹配的路由记录
console.log(route.matched)   // [parentRoute, currentRoute]
```

## 常见问题

### Q: 为什么路由切换后页面没有更新？
A: 检查是否正确配置了 `RouterView` 组件，并确保路由配置中的组件路径正确。

### Q: 如何处理路由权限？
A: 可以使用路由守卫和meta字段：
```js
router.beforeEach((to, from) => {
  if (to.meta.requiresAuth && !isAuthenticated()) {
    return '/login'
  }
})
```

### Q: 如何实现路由懒加载？
A: 使用动态导入语法：
```js
const routes = [
  {
    path: '/about',
    widget: () => import('./pages/About')
  }
]
```
