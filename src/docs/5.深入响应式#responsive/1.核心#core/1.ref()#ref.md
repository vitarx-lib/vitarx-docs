# ref()

`ref()` 函数用于创建一个响应式的引用对象（Ref），使任意值变成响应式数据。

## 基本用法

```js
import { ref } from 'vitarx'

// 创建一个包含数值的响应式引用
const count = ref(0)

// 访问值需要使用 .value 属性
console.log(count.value) // 0

// 修改值也需要使用 .value 属性
count.value++
console.log(count.value) // 1
```

## 类型定义

`ref()` 函数有多种重载形式，可以适应不同的使用场景：

```ts
// 传入值时，返回对应类型的 Ref 对象
function ref<T>(value: T, deep?: boolean): Ref<T>

// 不传值时，返回 Ref<any>，初始值为 undefined
function ref(value?: undefined, deep?: boolean): Ref

// 显式指定泛型时，不传值返回 Ref<T | undefined>
function ref<T>(value?: undefined, deep?: boolean): Ref<T | undefined>
```

## 参数说明

- `value`：可选参数，要代理的值，可以是任意类型
- `deep`：可选参数，是否深度代理，默认为 `true`。仅当值为对象类型时有效

## 深度代理

当 `deep` 参数为 `true` 时（默认值），如果 `ref` 的值是一个对象，该对象的所有嵌套属性也会被转换为响应式：

```js
const obj = ref({ count: 0, nested: { value: 'hello' } })

// 修改嵌套属性也会触发响应式更新
obj.value.nested.value = 'world'
```

如果不需要深度代理，可以使用 `shallowRef()` 函数或将 `deep` 参数设为 `false`：

```js
import { ref, shallowRef } from 'vitarx'

// 以下两种方式等效
const obj1 = ref({ count: 0 }, false)
const obj2 = shallowRef({ count: 0 })
```

## 注意事项

### 1. 避免嵌套响应式对象

当 `deep` 为 `true` 时，不应该将响应式对象（如另一个 Ref 或 Reactive 对象）作为 `ref()` 的值，这会导致警告：

```js
const innerRef = ref(0)
const outerRef = ref(innerRef) // 控制台会输出警告
```

### 2. 自动解构

在 `reactive` 对象中嵌套的 `ref` 会在访问时自动解构（unwrap）：

```js
import { ref, reactive } from 'vitarx'

const count = ref(0)
const state = reactive({ count })

// 无需使用 .value
console.log(state.count) // 0

// 修改 state.count 会同步更新 count.value
state.count = 1
console.log(count.value) // 1
```

注意：这种自动解构只发生在深层响应式对象中，浅层响应式对象不会自动解构。

### 3. 原始值转换

Ref 对象实现了 `Symbol.toPrimitive`，可以在某些上下文中自动转换为原始值：

```js
const count = ref(42)
const str = ref('hello')

// 数字上下文
console.log(count * 2) // 84

// 字符串上下文
console.log(str + ' world') // 'hello world'
```

## 相关 API

### isRef()

检查一个值是否为 Ref 对象：

```js
import { ref, isRef } from 'vitarx'

const count = ref(0)
console.log(isRef(count)) // true
console.log(isRef(0)) // false
```

### unRef()

如果参数是 Ref 则返回内部值，否则返回参数本身：

```js
import { ref, unRef } from 'vitarx'

const count = ref(0)
console.log(unRef(count)) // 0
console.log(unRef(1)) // 1
```

### shallowRef()

创建一个浅层响应式的 Ref 对象（等同于 `ref(value, false)`）：

```js
import { shallowRef } from 'vitarx'

const state = shallowRef({ count: 0 })
// 只有 .value 的替换会触发响应式更新
// state.value.count++ 不会触发更新
```
