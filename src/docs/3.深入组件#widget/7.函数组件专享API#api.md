# 函数组件专享API

## useViewForceUpdating

`useViewForceUpdating`是一个函数组件专享的Hook，用于在函数组件中强制更新视图。

```jsx
import { useViewForceUpdating } from 'vitarx'

function App() {
  const forceUpdating = useViewForceUpdating()
  let count = 0
  const updateCount = () => {
    count++
    forceUpdating()
  }
  return (
    <div>
      <h1>Hello, Vitarx! - {count}</h1>
      <button onClick={updateCount}>强制更新视图</button>
    </div>
  )
}
```

## defineExpose

`defineExpose`是一个函数组件专享的API，用于在函数组件中暴露一些数据或函数到组件实例上。

```jsx
import { defineExpose } from 'vitarx'
function  Counter() {
  const count = ref(0)
  const increment = () => {
    count.value++
  }
  defineExpose({
    count,
    increment
  })
  return (
    <div>
      <h1>Hello, Vitarx! - {count.value}</h1>
      <button onClick={increment}>Increment</button>
    </div>
  )  
}

function App() {
  const counter = refEl<{ count: number, increment: () => void }>()

  return (
    <div>
      <Counter ref={counter} />
      <button onClick={() => {
        counter.value?.increment()
      }}>Increment</button>
    </div>
  )
}
```
