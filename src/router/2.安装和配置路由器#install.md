# 安装配置

## 安装

使用 npm 安装 Vitarx Router：

```bash
npm install vitarx-router
```

## 基本配置

创建路由器实例时，你需要提供一些基本配置：

```js
import { createRouter, defineRoutes } from 'vitarx-router'

const router = createRouter({
  // 路由模式，默认值是hash，推荐使用path
  mode: 'path', // 'path' | 'hash' | 'memory'
  
  // 路由规则
  routes: defineRoutes(
    // 在这里定义你的路由
  ),
  // 基础路径
  base: '/', // 可选，默认为 '/'
})
```

## 路由模式

Vitarx Router 支持三种路由模式：

- **path 模式**：使用 HTML5 History API，URLs 更友好
  ```
  example.com/users/1
  ```

- **hash 模式**：使用 URL hash，兼容性更好
  ```
  example.com/#/users/1
  ```

- **memory 模式**：完全的内存路由，用于非浏览器环境

## 在应用中使用

在你的应用入口文件中注册路由器：

```js
import { createApp } from 'vitarx'
// 假设在router中默认导出了已经创建好的router实例
import router from './router'

const app = createApp('#root').use(router)
```
