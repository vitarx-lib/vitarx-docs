# 渲染列表

在 Vitarx 中，你可以使用 js 数组的 `map` 方法来渲染列表数据。本章节将介绍如何在 Vitarx 中高效地渲染列表。

## 基本列表渲染

使用数组的 `map()` 方法可以将数组数据转换为 JSX 元素列表：

```jsx
import { ref } from 'vitarx';

function FruitList() {
  const fruits = ref(['苹果', '香蕉', '橙子', '葡萄']);
  
  return (
    <div>
      <h2>水果列表</h2>
      <ul>
        {fruits.value.map(fruit => (
          <li>{fruit}</li>
        ))}
      </ul>
    </div>
  );
}
```

## 使用 key 属性

当渲染列表时，应该为每个列表项提供一个唯一的 `key` 属性。这有助于 Vitarx 识别哪些项发生了变化，从而提高渲染性能：

```jsx
import { ref } from 'vitarx';

function UserList() {
  const users = ref([
    { id: 1, name: '张三' },
    { id: 2, name: '李四' },
    { id: 3, name: '王五' }
  ]);
  
  return (
    <div>
      <h2>用户列表</h2>
      <ul>
        {users.value.map(user => (
          <li key={user.id}>{user.name}</li>
        ))}
      </ul>
    </div>
  );
}
```

> **注意**：`key` 应该是稳定、唯一的标识符。避免使用数组索引作为 key，特别是当列表项的顺序可能会改变时。

## 条件渲染列表

在实际应用中，我们经常需要根据某些条件决定是否渲染列表中的某些项。Vitarx 提供了两种主要方式来实现条件渲染列表：

### 方法一：使用 filter 方法筛选数据

使用 `filter()` 方法可以先筛选出符合条件的数据，然后再渲染：

```jsx
import { ref, build } from 'vitarx';

function TaskList() {
  const tasks = ref([
    { id: 1, text: '学习 Vitarx', completed: true },
    { id: 2, text: '创建一个应用', completed: false },
    { id: 3, text: '部署应用', completed: false }
  ]);
  
  // 只显示未完成的任务
  return build(() => (
    <div>
      <h2>待完成任务列表</h2>
      <ul>
        {tasks.value
          .filter(task => !task.completed)
          .map(task => (
            <li key={task.id}>{task.text}</li>
          ))
        }
      </ul>
      <p>未完成任务数: {tasks.value.filter(task => !task.completed).length}</p>
    </div>
  ));
}
```

### 方法二：在 map 方法中使用条件判断

在 `map()` 方法中使用条件运算符或逻辑与（&&）来决定是否渲染某个项：

```jsx
import { ref, build } from 'vitarx';

function TaskList() {
  const tasks = ref([
    { id: 1, text: '学习 Vitarx', completed: true },
    { id: 2, text: '创建一个应用', completed: false },
    { id: 3, text: '部署应用', completed: false }
  ]);
  const showCompleted = ref(false);
  
  return build(() => (
    <div>
      <h2>任务列表</h2>
      <label>
        <input 
          type="checkbox" 
          checked={showCompleted.value}
          onChange={() => showCompleted.value = !showCompleted.value}
        />
        显示已完成任务
      </label>
      <ul>
        {tasks.value.map(task => (
          // 只有当任务未完成或showCompleted为true时才渲染该项
          (!task.completed || showCompleted.value) && (
            <li key={task.id} style={{ color: task.completed ? 'green' : 'red' }}>
              {task.text} {task.completed ? '(已完成)' : '(未完成)'}
            </li>
          )
        ))}
      </ul>
    </div>
  ));
}
```

## 动态更新列表

结合响应式状态和事件处理，可以实现动态更新列表：

```jsx
import { ref, build } from 'vitarx';

function TodoList() {
  const newTask = ref('');
  const todos = ref([
    { id: 1, text: '学习 Vitarx 基础', completed: false },
    { id: 2, text: '创建一个 Todo 应用', completed: false }
  ]);
  
  // 添加新任务
  const addTodo = () => {
    if (newTask.value.trim()) {
      todos.value.push({
        id: Date.now(),
        text: newTask.value,
        completed: false
      });
      newTask.value = '';
    }
  };
  
  // 切换任务状态
  const toggleTodo = (id) => {
    const todo = todos.value.find(item => item.id === id);
    if (todo) {
      todo.completed = !todo.completed;
    }
  };
  
  // 删除任务
  const removeTodo = (id) => {
    todos.value = todos.value.filter(item => item.id !== id);
  };
  
  return build(() => (
    <div>
      <h2>待办事项</h2>
      <div>
        <input 
          type="text" 
          value={newTask.value}
          onInput={(e) => newTask.value = e.target.value}
          placeholder="添加新任务"
        />
        <button onClick={addTodo}>添加</button>
      </div>
      <ul>
        {todos.value.map(todo => (
          <li key={todo.id}>
            <span 
              style={{ 
                textDecoration: todo.completed ? 'line-through' : 'none',
                color: todo.completed ? 'gray' : 'black'
              }}
              onClick={() => toggleTodo(todo.id)}
            >
              {todo.text}
            </span>
            <button onClick={() => removeTodo(todo.id)}>删除</button>
          </li>
        ))}
      </ul>
      <div>
        <p>总计: {todos.value.length} 项, 已完成: {todos.value.filter(t => t.completed).length} 项</p>
      </div>
    </div>
  ));
}
```

通过上面的示例，你可以看到如何在 Vitarx 中渲染和管理列表数据。列表渲染是前端开发中的常见需求，掌握这些技巧将帮助你构建更加动态和交互性强的用户界面。
