# 工具函数

Vitarx 提供了一组实用的工具函数，涵盖深拷贝、类型检测、防抖节流、字符串转换、延迟控制、日志输出等常见场景。这些函数都经过精心设计，可以直接在项目中使用，无需额外安装依赖。

- [深拷贝](./1.deep-clone.md) — deepClone 深度克隆对象
- [类型检测](./2.type-checking.md) — isXxx 系列类型判断函数
- [防抖与节流](./3.debounce-throttle.md) — debounce 和 throttle
- [延迟与超时](./4.delay-timeout.md) — sleep 和 withDelayTimeout
- [字符串工具](./5.string-utils.md) — 命名转换与首字母大写
- [对象工具](./6.object-utils.md) — 深度合并、属性弹出、数组转换
- [日志工具](./7.logger.md) — Logger、logger、调用栈追踪
