# 创建应用实例

本章节中所有的示例代码都应该写在 `main.js/ts` 文件中，main.ts 文件做为项目的入口模块。

## 创建和挂载

每个 `Vitarx` 应用都是通过 `createApp` 助手函数创建一个新的**应用实例**：

```js
import { createApp } from 'vitarx'

// createApp 第一个参数是需要挂载的容器元素，可以是字符串选择器，也可以是 DOM 元素实例
const app = createApp('#root')
```

## 渲染视图

需要为应用渲染一个根组件做为视图，支持传入 `VNode` 节点对象，但它的类型必须是组件，不能是普通节点，如：div。

```js
import { createApp } from 'vitarx'
import App from './App.js'

const app = createApp('#root').render(App,{
  /* 根组件选项 */
})
```

## 多应用实例

```js
const app1 = createApp('#root1').render(App1)
const app2 = createApp('#root2').render(App2)
const app3 = createApp('#root3').render(App3)
```

## 实例方法

### **render**

渲染一个根组件，支持传入 `VNode` 节点对象，但它的类型必须是组件，不能是普通节点，如：div。

### **update**

使根组件视图强制更新

### **unmount**

卸载应用实例，卸载后应用实例将不再响应事件，并且将移除挂载的根节点。

### **activate**

激活应用实例，激活后应用实例将开始响应事件，并且将挂载到挂载的根节点。

### **deactivate**

冻结应用实例，冻结后应用实例将不再响应事件，并且将移除挂载的根节点。

### **register**

注册任意数据到应用实例。

```js
app.register('key', 'AnyValue')
```

### **unregister**

从应用实例中移除注册的数据。

```js
app.unregister('key')
```

### **get**

从应用实例中获取一个已被注册的数据

```js
app.get('key')
```

### **provide**

此方法的用途是挂载一个数据到根组件节点，在子组件中通过 `inject` 来获取根组件提供的数据。

注意它和 [`register`](#register) 的区别是，`provide` 是挂载到根组件节点，而 `register` 是挂载到应用实例上。

```js
app.provide('test', 1)


// 以下是组件文件内容
import { inject } from 'vitarx'

// 在函数组件中获取根组件提供的数据
const YourWidget = () => {
  const value = inject('test') // value === 1
  return <div>{value}</div>
}
```

### **use**

安装应用插件。插件是一个接收应用实例作为参数的函数，可用于扩展应用功能。

**注意：** `use` 方法只能安装函数式插件，不支持对象式插件。

```js
// 定义一个插件
const myPlugin = (app) => {
  // 扩展应用功能
  app.provide('pluginData', { message: '来自插件的数据' })
  
  // 注册全局工具函数
  app.register('formatDate', (date) => {
    return new Date(date).toLocaleDateString()
  })
}

// 安装插件
app.use(myPlugin)

// 链式调用
app.use(pluginA)
  .use(pluginB)
  .use(pluginC)
```

插件可以接收额外的选项：

```js
// 定义带选项的插件
const configPlugin = (app, options) => {
  // 使用选项配置插件行为
  const { prefix = 'default' } = options || {}
  
  app.provide(`${prefix}Config`, options)
}

// 安装带选项的插件
app.use(configPlugin, { prefix: 'api', baseURL: 'https://api.example.com' })
```
