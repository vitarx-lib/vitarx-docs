# 类型化路由

类型化路由是为了能在编译时提前发现路由错误。通过生成路由索引的类型声明文件，可以在开发时获得更好的类型提示和检查。

## 使用方法

内置提供了一个`makeTypeRoute`函数，用来创建类型化路由。该函数位于`vitarx-router/scripts/make-type`中：

```js
import { makeTypeRoute } from 'vitarx-router/scripts/make-type'
import routes from './routes'

// 生成类型声明文件
makeTypeRoute(
  routes,           // 路由配置表
  ['custom'],       // 自定义的路由名称或路径
  './route.d.ts'    // 可选，类型声明文件的输出路径
)
```

### 参数说明

- `routes`: 路由配置表，包含路由的完整配置信息
- `custom`: 自定义的路由名称或路径数组，例如`['/home', 'home']`
- `writePath`: 类型声明文件的输出路径，必须使用绝对路径。推荐使用 Node.js 的 path 模块来构建正确的路径：

```js
import path from 'path'

makeTypeRoute(
  routes,
  ['custom'],
  path.resolve(__dirname, './route.d.ts')
)
```

> 注意：使用相对路径可能会导致类型声明文件生成在意外的位置，因此强烈建议使用绝对路径。

## 工作原理

### 路由索引生成

`makeTypeRoute`函数会递归遍历路由表，收集所有有效的路由路径和名称：

1. 对于每个路由配置：
   - 如果路由有`widget`属性，收集其完整路径
   - 如果路由有`name`属性，收集其名称
   - 如果路由有子路由，递归处理子路由

2. 路径格式化规则：
   - 统一以`/`开头
   - 去除所有空格
   - 处理重复的`/`
   - 去除末尾的`/`（根路径`/`除外）

### 类型声明文件

生成的类型声明文件（默认为`route.type.d.ts`）包含一个联合类型`VitarxRouterRouteIndexTyped`，它包含了所有有效的路由路径和名称。例如：

```ts
type VitarxRouterRouteIndexTyped = '/home' | '/about' | 'home' | 'about' | 'custom';
```

通过这个类型声明，你可以在开发时获得更好的类型提示和检查，避免输入错误的路由路径或名称。
