# 介绍

## 什么是 Vitarx?

`Vitarx` 是一个创新的前端框架，它结合了 `Vue` 的响应式系统设计和 `React` 的 `JSX` 语法的优点，为开发者提供了一种全新的开发体验。

通过 `Vitarx`，您可以使用熟悉的 JSX 语法来构建组件，同时享受响应式系统的简洁和高效。

## 为什么叫 Vitarx?

`Vitarx` 并不是一个标准的英文词汇，将它拆解为：
1. `Vita`：代表着有活力，有生命
2. `Rx`：代表 `React Jsx`

总体来说，`Vitarx` 的名字就是一种新的思考方式，它将 `Vue` 与 `React` 的概念结合在一起，以表达一种新地开发理念。

## 为什么要打造 Vitarx?

在前端开发领域，我们面临着一些亟待解决的痛点和挑战：

### 开发体验的痛点

- **语言障碍**：使用 Vue、React 等主流框架时，`Jsdoc` 文档多为英文，这给国内开发者带来了阅读障碍。开发过程中频繁需要翻译文档或在中文社区站点中查找用例，难以脱离文档高效开发。

- **框架机制差异**：React 的函数式组件每次更新都会重新执行整个函数，而 Vue 的响应式系统则采用不同的更新机制。这种差异导致开发者在不同框架间切换时，编程习惯和思维模式需要不断调整，增加了学习和适应成本。

### Vitarx 的解决之道

基于以上痛点和挑战，我们打造了 Vitarx：

- **中文优先**：Vitarx 提供完善的中文文档和开发指南，消除语言障碍，让国内开发者能够更加流畅地进行开发。

- **融合最佳实践**：汲取 Vue 响应式系统的简洁高效和 React JSX 语法的灵活强大，Vitarx 为开发者提供了统一且直观的开发体验，无需在不同的编程范式间切换。

- **开发效率提升**：通过简化 API 设计和优化开发流程，Vitarx 帮助开发者减少样板代码，专注于业务逻辑的实现，显著提升开发效率。

Vitarx 不仅是一个前端框架，更是一种开发理念的革新，旨在为开发者提供更加友好、高效、统一的开发体验。

## 文档原则

使用直白的语言，**尽量**少介绍晦涩难懂的技术细节与底层概念；

写文档时要转变思维，以小白的角度去审视别人能不能看得懂；

每个功能模块必须要有一个完整示例，且示例代码要可读性高，不能以小白看不懂的形式编写示例！
