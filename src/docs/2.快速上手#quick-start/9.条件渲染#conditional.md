# 条件渲染

在 Vitarx 中，条件渲染是控制组件是否显示的重要机制。本章节将介绍如何在 Vitarx 中实现条件渲染，帮助你根据不同的状态和条件展示不同的 UI 内容。

## 使用三元运算符

最简单的条件渲染方式是使用 JavaScript 的三元运算符 (`? :`)

```jsx
import { ref, build } from 'vitarx';

function ConditionalGreeting() {
  const isLoggedIn = ref(true);
  
  return build(() => (
    <div>
      {isLoggedIn.value 
        ? <h1>欢迎回来！</h1> 
        : <h1>请登录</h1>
      }
      <button onClick={() => isLoggedIn.value = !isLoggedIn.value}>
        {isLoggedIn.value ? '登出' : '登录'}
      </button>
    </div>
  ));
}
```

## 使用逻辑与运算符

对于只需要在条件为真时渲染内容的情况，可以使用逻辑与运算符 (`&&`)：

```jsx
import { ref, build } from 'vitarx';

function Notifications() {
  const messages = ref(['您有一条新消息']);
  const clearMessages = () => {
    messages.value = [];
  };
  
  return build(() => (
    <div>
      {messages.value.length > 0 && (
        <div>
          <h2>通知</h2>
          <ul>
            {messages.value.map((message, index) => (
              <li key={index}>{message}</li>
            ))}
          </ul>
          <button onClick={clearMessages}>清除所有通知</button>
        </div>
      )}
      
      {messages.value.length === 0 && (
        <p>没有新通知</p>
      )}
    </div>
  ));
}
```

## 条件渲染组件

你可以创建专门的组件来处理不同的条件状态：

```jsx
import { ref, build } from 'vitarx';

// 登录状态组件
function LoggedIn({ username, onLogout }) {
  return (
    <div>
      <h1>欢迎，{username}！</h1>
      <button onClick={onLogout}>登出</button>
    </div>
  );
}

// 未登录状态组件
function LoggedOut({ onLogin }) {
  return (
    <div>
      <h1>请登录以继续</h1>
      <button onClick={onLogin}>登录</button>
    </div>
  );
}

// 主组件
function AuthExample() {
  const isLoggedIn = ref(false);
  const username = ref('用户');
  
  const handleLogin = () => {
    isLoggedIn.value = true;
  };
  
  const handleLogout = () => {
    isLoggedIn.value = false;
  };
  
  return build(() => (
    <div>
      {isLoggedIn.value 
        ? <LoggedIn username={username.value} onLogout={handleLogout} /> 
        : <LoggedOut onLogin={handleLogin} />
      }
    </div>
  ));
}
```

## 使用变量存储元素

在更复杂的情况下，你可以使用变量来存储要渲染的元素：

```jsx
import { ref, build } from 'vitarx';

function TabsExample() {
  const activeTab = ref('home');
  
  const setTab = (tab) => {
    activeTab.value = tab;
  };
  
  return build(() => {
    let tabContent;
    
    switch (activeTab.value) {
      case 'home':
        tabContent = <div>首页内容</div>;
        break;
      case 'profile':
        tabContent = <div>个人资料内容</div>;
        break;
      case 'settings':
        tabContent = <div>设置内容</div>;
        break;
      default:
        tabContent = <div>未找到内容</div>;
    }
    
    return (
      <div>
        <div className="tabs">
          <button 
            onClick={() => setTab('home')}
            className={activeTab.value === 'home' ? 'active' : ''}
          >
            首页
          </button>
          <button 
            onClick={() => setTab('profile')}
            className={activeTab.value === 'profile' ? 'active' : ''}
          >
            个人资料
          </button>
          <button 
            onClick={() => setTab('settings')}
            className={activeTab.value === 'settings' ? 'active' : ''}
          >
            设置
          </button>
        </div>
        
        <div className="tab-content">
          {tabContent}
        </div>
      </div>
    );
  });
}
```

## 阻止组件渲染

在某些情况下，你可能希望完全隐藏组件，即使它已经被渲染。这可以通过返回 `片段节点` 来实现：

```jsx
import { ref, build } from 'vitarx';

function WarningBanner(props) {
  
  return <>
    {
     props.warn && 
     <div className="warning">警告：您正在执行敏感操作！</div>
    }
  </>;
}

function WarningExample() {
  const showWarning = ref(true);
  
  return build(() => (
    <div>
      <WarningBanner warn={showWarning.value} />
      <button onClick={() => showWarning.value = !showWarning.value}>
        {showWarning.value ? '隐藏警告' : '显示警告'}
      </button>
    </div>
  ));
}
```

通过掌握条件渲染技巧，你可以根据应用的状态和用户的交互，动态地控制界面的显示内容，创建更加灵活和交互性强的用户界面。
