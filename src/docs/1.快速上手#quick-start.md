# 快速上手

## 创建一个 `Vitarx` 应用

:::info:前提条件
1. 熟悉 JavaScript/TypeScript
2. 熟悉 命令行
3. 已安装 18.x 或更高版本的 [Node.js](https://nodejs.org/)
:::

本节将介绍如何创建一个 `Vitarx` 应用。

在你的工作目录下执行以下命令

```bash
npm create vitarx@latest
```
或者使用 yarn：

```bash
yarn create vitarx
```

这一指令将会安装并执行 [create-vitarx](https://www.npmjs.com/package/create-vitarx)，它是 Vitarx 官方的项目脚手架工具。

执行命令过后按照如下步骤操作即可运行应用：

1. 按照提示选择：
    - 项目名称
    - 开发语言（TypeScript/JavaScript）
    - 项目模板

2. 等待项目创建完成

3. 启动项目
    ```bash
    cd <your-project-name>
    npm install
    npm run dev # 启动开发服务器
    ```
   
4. 在浏览器中访问 `http://localhost:5173` 即可查看的所创建的应用，站点内容则是你所选择的项目模板中的 `demo`





## 发布应用

当你已完成项目开发时，你需要通过如下命令将项目打包为生产环境可用的源代码。

```bash
npm run build # 构建生产环境代码
```

## 预览应用

如果你已经执行了构建命令，则可以通过如下命令预览应用。

```bash
npm run preview # 启动预览服务器
```

## 通过 CDN 使用

你可以借助 script 标签直接通过 CDN 来使用 Vitarx

```html
<script src="https://unpkg.com/vitarx@1.0.3/dist/vitarx.umd.js"></script>
```

这里我们引入了 Vitarx 的 UMD 版本，它将 Vitarx 作为全局变量 `Vitarx` 暴露在浏览器中。  

你可以通过 `Vitarx` 全局变量访问到 Vitarx 的所有API，例如：

```js
const counter = Vitarx.ref(0)
Vitarx.watch(counter,() => {
  console.log(`The counter is now ${counter.value}`)
})
counter.value++
```

虽然 Vitarx 支持以 UMD 形式使用，但并不推荐在浏览器中直接使用它，我们建议使用现代化构建工具如 `vite` 构建项目！
