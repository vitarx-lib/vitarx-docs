# 导航守卫

导航守卫主要用来通过跳转或取消的方式守卫导航。有多种机会植入路由导航过程中：全局的、单个路由独享的、或者组件级的。

## 全局前置守卫

你可以使用 `router.beforeEach` 注册一个全局前置守卫：

```ts
const router = createRouter({
  beforeEach: (to, from) => {
    // 返回 false 以取消导航
    return false

    // 返回一个路由地址以进行重定向
    return { path: '/login' }

    // 返回一个路由地址进行重定向
    return '/login'

    // 返回一个路由name进行重定向
    return 'login'

    // 返回 undefined 或 true 以正常导航
    return true

    // 也可以返回Promise
    return new Promise((resolve, reject) => {
      setTimeout(() => {
        resolve(true)
      }, 1000)
    })
  }
})
```

当一个导航触发时，全局前置守卫按照创建顺序调用。守卫是异步解析执行，此时导航在所有守卫 resolve 完之前一直处于等待中。

每个守卫方法接收两个参数：

- **to**: 即将要进入的目标路由对象
- **from**: 当前导航正要离开的路由对象

可以返回的值如下：

- `false`: 取消当前的导航。
- 路由path或name: 就像你调用 `router.push('/path')` 一样
- 路由目标对象：和直接返回一个路由path或name是同理的
- `true` 或 `undefined`: 验证导航，调用下一个导航守卫

## 全局后置钩子

你也可以注册全局后置钩子，然而和守卫不同的是，这些钩子不能改变导航本身：

```ts
const router = createRouter({
  afterEach: (to, from) => {
    // 记录路由访问
    sendToAnalytics(to.path)
  }
})
```

## 路由独享的守卫

你可以在路由配置上直接定义 `beforeEnter` 和 `afterEnter` 守卫：

```ts
const routes = [
  {
    path: '/users/{id}',
    widget: UserDetails,
    beforeEnter: (to) => {
      // 检查用户是否有权限访问
      if (!hasAccess(to.params.id)) {
        return '/403'
      }
    },
    afterEnter: (to) => {
      // 记录用户访问详情
      logAccess(to.params.id)
    }
  }
]
```

## 完整的导航解析流程

1. 导航被触发
2. 在失活的组件里调用 `beforeRouteLeave` 守卫
3. 调用全局的 `beforeEach` 守卫
4. 在重用的组件里调用 `beforeRouteUpdate` 守卫
5. 在路由配置里调用 `beforeEnter`
6. 解析异步路由组件
7. 在被激活的组件里调用 `beforeRouteEnter`
8. 调用全局的 `afterEach` 钩子
9. 触发 DOM 更新
10. 调用 `beforeRouteEnter` 守卫中传给 next 的回调函数

## 实际应用场景

### 登录验证

```ts
const router = createRouter({
  beforeEach: (to) => {
    // 检查用户是否已登录
    const isAuthenticated = checkAuth()
    
    if (to.path !== '/login' && !isAuthenticated) {
      // 将用户重定向到登录页面
      return '/login'
    }
  }
})
```

### 权限控制

```ts
const router = createRouter({
  beforeEach: (to) => {
    // 检查用户权限
    const userRole = getUserRole()
    
    if (to.meta.requiresAdmin && userRole !== 'admin') {
      // 用户没有权限，重定向到403页面
      return '/403'
    }
  }
})
```

### 数据预加载

```ts
const routes = [
  {
    path: '/user/{id}',
    component: UserDetails,
    beforeEnter: async (to) => {
      try {
        // 预加载用户数据
        await loadUserData(to.params.id)
      } catch (error) {
        // 加载失败时重定向到错误页面
        return '/error'
      }
    }
  }
]
```
