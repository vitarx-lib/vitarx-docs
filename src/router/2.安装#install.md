# 安装

## 包管理器

使用 npm 安装 Vitarx Router：

```bash
npm install vitarx-router
```

## 脚手架

如果你打算启动一个全新的 Vitarx 项目，建议使用 [create-vitarx](https://www.npmjs.com/package/create-vitarx) 脚手架工具，
它能创建一个基于 Vite 构建器的全新 Vitarx 项目，并包含 Vitarx Router 作为依赖项。

```bash
npm create vitarx@latest
```

具体如何创建一个全新的项目，请参考 [快速上手](/docs/quick-start)。

## 直接下载/CDN

你可以借助 script 标签直接通过 CDN 来使用 Vitarx

```html
<script src="https://unpkg.com/vitarx-router@latest/dist/vitarx-router.umd.js"></script>
```
这将把 Vitarx Router 暴露在全局的 `VitarxRouter` 对象上，例如 `VitarxRouter.createRouter(...)`。
