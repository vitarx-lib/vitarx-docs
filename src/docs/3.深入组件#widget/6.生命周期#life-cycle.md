# 生命周期

## 组件的生命周期
组件的生命周期是指组件从创建到销毁的过程中，组件会经历一系列的状态变化，这些状态变化会触发组件的生命周期函数。

## 生命周期钩子

Vitarx 为组件提供了一系列的生命周期钩子，让你可以在组件的不同阶段执行自定义的逻辑。

### 创建阶段

#### onBeforeCreate
- 触发时机：组件构造完成前触发
- 适用场景：定义组件的默认 `Props`
- 注意事项：此钩子仅类组件支持，函数组件不支持

#### onCreated
- 触发时机：组件创建后，挂载到 DOM 树前触发
- 适用场景：设置组件的初始状态，发起网络请求
- 注意事项：此时组件的 DOM 元素还未创建，不能操作 DOM

### 挂载阶段

#### onBeforeMount
- 触发时机：组件挂载到 DOM 树前触发
- 适用场景：可以返回一个 DOM 元素作为组件的挂载容器
- 注意事项：此时组件的 DOM 元素还未创建，不能操作 DOM
- 返回值：可以返回一个 DOM 元素作为组件的挂载容器

#### onMounted
- 触发时机：组件挂载到 DOM 树后触发
- 适用场景：访问和操作 DOM、发起网络请求、添加事件监听器
- 注意事项：此时可以安全地访问组件的 DOM 元素

### 更新阶段

#### onBeforeUpdate
- 触发时机：组件更新前触发
- 适用场景：在组件更新前访问现有的 DOM 状态
- 注意事项：避免在此钩子中修改组件状态，可能导致无限更新循环

#### onUpdated
- 触发时机：组件更新后触发
- 适用场景：访问更新后的 DOM 状态
- 注意事项：避免在此钩子中修改组件状态，可能导致无限更新循环

### 卸载阶段

#### onBeforeUnmount
- 触发时机：组件卸载前触发
- 适用场景：清理定时器、取消事件监听、取消网络请求
- 注意事项：此时组件仍然完全正常工作

#### onUnmounted
- 触发时机：组件卸载后触发
- 适用场景：执行最终的清理工作
- 注意事项：此时组件的 DOM 元素已被移除

### 特殊钩子

#### onError
- 触发时机：组件渲染或构建过程中出现错误时触发
- 适用场景：错误处理和降级展示
- 参数：
  - error: 捕获到的错误对象
  - info: 错误信息对象，包含错误来源和实例信息 具体类型参考 [ErrorInfo](#ErrorInfo)
- 返回值：如果 [info.source](#ErrorSource) 为 `build` | `render` 时可以返回一个备用元素用于展示

#### onBeforeRemove
- 触发时机：组件的 DOM 元素被移除前触发
- 适用场景：执行元素移除前的过渡动画
- 参数：
  - el: 当前组件的根元素
  - type: 触发类型（'unmount' 或 'deactivate'）
- 返回值：可以返回一个 Promise 来延迟元素的移除

#### onDeactivated
- 触发时机：组件被缓存时触发（需配合 [KeepAlive](/docs/built/keep-alive) 组件使用）
- 适用场景：暂停一些消耗性能的任务

#### onActivated
- 触发时机：被缓存的组件重新激活时触发
- 适用场景：恢复组件的状态或重新获取数据

## 使用方式

### 类组件中使用

类组件通过继承 `Widget` 类（内部继承了 `LifeCycle`）来使用生命周期方法：

```js
import { Widget } from 'vitarx'

class MyWidget extends Widget {
  onCreated() {
    console.log('组件已创建')
  }

  onMounted() {
    console.log('组件已挂载')
  }

  onBeforeUnmount() {
    console.log('组件即将卸载')
  }

  build() {
    return <div>Hello World</div>
  }
}
```

### 函数组件中使用

函数组件通过导入并调用相应的钩子函数来注册生命周期钩子：

```js
import { onMounted, onBeforeUnmount } from 'vitarx'

function MyComponent() {
  onMounted(() => {
    console.log('组件已挂载')
  })

  onBeforeUnmount(() => {
    console.log('组件即将卸载')
  })

  return <div>Hello World</div>
}
```

### 过渡动画示例

使用 `onBeforeRemove` 实现元素移除前的淡出动画：

```js
import { onBeforeRemove } from 'vitarx'

function FadeComponent() {
  onBeforeRemove((el) => {
    // 返回 Promise 延迟元素移除
    return new Promise((resolve) => {
      el.style.transition = 'opacity 0.3s'
      el.style.opacity = '0'
      setTimeout(resolve, 300)
    })
  })

  return <div>Fade Out Component</div>
}
```

## 生命周期图示

```
组件创建
   ↓
onBeforeCreate
   ↓
onCreated
   ↓
onBeforeMount
   ↓
 挂载 DOM
   ↓
onMounted
   ↓
   ↓    ← 数据更新
onBeforeUpdate
   ↓
 更新 DOM
   ↓
onUpdated
   ↓
   ↓    ← 组件卸载
onBeforeUnmount
   ↓
移除 DOM
   ↓
onUnmounted
```

注意：
- 所有生命周期钩子的 `this` 会自动绑定到组件实例上
- 避免在 `onBeforeUpdate` 和 `onUpdated` 中修改组件状态，可能导致无限更新循环
- 在使用 `onBeforeRemove` 时，确保在动画完成后调用 `resolve`
- 生命周期钩子只能在组件的顶层作用域中使用，不能在条件语句或循环中使用


## TypeScript类型

### LifeCycleHooks
```ts
/** 生命周期钩子枚举 */
export enum LifeCycleHooks {
  created = 'onCreated',
  beforeMount = 'onBeforeMount',
  mounted = 'onMounted',
  deactivated = 'onDeactivated',
  activated = 'onActivated',
  beforeUpdate = 'onBeforeUpdate',
  updated = 'onUpdated',
  error = 'onError',
  unmounted = 'onUnmounted',
  beforeUnmount = 'onBeforeUnmount',
  beforeRemove = 'onBeforeRemove'
}

/**
 * 生命周期钩子名联合类型
 */
export type LifeCycleHookNames = keyof typeof LifeCycleHooks
/**
 * 生命周期钩子方法名联合类型
 */
export type LifeCycleHookMethods = `${LifeCycleHooks}`
```

### ErrorSource

- build: 构建视图阶段
- render: 渲染视图阶段
- update: 更新视图阶段
- listener: 事件监听器
- hook:${string}: 生命周期钩子

```ts
/**
 * 错误来源联合类型
 */
export type ErrorSource =
  | 'build'
  | 'render'
  | 'update'
  | 'listener'
  | `hook:${Exclude<LifeCycleHookNames, 'error'>}`
```


### ErrorInfo
```ts
/**
 * 错误信息对象接口
 */
export interface ErrorInfo {
  /**
   * 错误来源
   */
  source: ErrorSource
  /**
   * 抛出异常的实例
   */
  instance: Widget
}
```
