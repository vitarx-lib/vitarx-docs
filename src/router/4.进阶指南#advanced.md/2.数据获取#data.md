# 数据获取

在构建应用时，我们经常需要在导航到某个路由后从服务器获取数据。例如，在渲染用户信息之前，我们需要从服务器获取该用户的数据。我们可以通过两种方式来实现这一需求：

1. **导航完成后获取数据**：先完成导航，然后在组件的生命周期钩子中获取数据。在获取数据时显示加载状态。

2. **导航完成前获取数据**：导航完成之前获取数据，在数据获取成功后执行导航。

选择使用哪种方式取决于用户体验的要求。

## 导航完成后获取数据

当我们使用这种方式时，我们会马上导航和渲染组件，然后在组件的 `onMounted` 钩子中获取数据。这让我们有机会展示加载状态，同时也可以在不同视图中进行数据获取。

```tsx
import { ref,watch } from 'vitarx';

function Post() {
  const post = ref(null);
  const loading = ref(true);
  const route = useRoute();
  const fetchData = (id) => {
    try {
      loading.value = true;
      // 从服务器获取数据
      const response = await fetch(`/api/posts/${id}`);
      post.value = await response.json();
    } catch (error) {
      console.error(error);
    } finally {
      loading.value = false;
    }
  }

  // 初始化加载一次数据
  fetchData(route.params.id);
  // 仅路由参数变化不会重新创建组件，因此需要监听路由参数的变化并重新获取数据
  watch(() => route.params.id, fetchData,{batch:false})

  return (
    <div>
      {loading.value ? (
        <p>Loading...</p>
      ) : (
        <div>
          <h2>{post.value.title}</h2>
          <p>{post.value.content}</p>
        </div>
      )}
    </div>
  );
}
```

## 导航完成前获取数据

有时我们可能希望在导航完成之前就获取数据。我们可以在路由守卫中执行数据获取，并且只在获取完成后才导航到目标路由。

```tsx
import { createRouter } from 'vitarx-router';

const router = createRouter({
  // ...
  routes: [
    {
      path: '/post/{id}',
      widget: Post,
      beforeEnter: async (to) => {
        try {
          // 获取数据
          const response = await fetch(`/api/posts/${to.params.id}`);
          const post = await response.json();
          // 将数据合并到参数中，这样传递给组件的 props 中
          // 使用Object.assign的原因是to.params参数是被定义为只读类型的，使用Object.assign可以避免TS报错
          Object.assign(to.params, { post });
          // Post 组件可以接收到的 props 是：
          // { id: '1', post: { title: 'Hello', content: 'World' } }
        } catch (error) {
          // 处理错误，例如重定向到错误页面
          return { path: '/error' };
        }
      }
    }
  ]
});
```

然后在组件中可以通过props访问数据：

```tsx
function Post(props) {
  // props是响应式的，且路由参数更新过后props也会更新
  // 因此可以直接使用props.post来访问数据，视图会自动更新
  return (
    <div>
      <h2>{props.post.title}</h2>
      <p>{props.post.content}</p>
    </div>
  );
}
```

## 获取query参数

query参数可以通过`useRoute`获取到，例如：

```tsx
const route = useRoute();
const query = route.query;

watch(() => route.query, (newQuery, oldQuery) => {
  // 当query参数变化时，会触发这个回调函数
})
```
