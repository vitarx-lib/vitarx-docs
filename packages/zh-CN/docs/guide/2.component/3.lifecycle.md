# 生命周期

Vitarx 的组件从创建到销毁会经历多个阶段，每个阶段都提供了对应的钩子函数，让你可以在特定时机执行逻辑。与 Vue 不同的是，Vitarx 的函数组件只执行一次（不会因数据变化而重新执行），因此生命周期钩子只需注册一次。

## 生命周期钩子一览

| 钩子            | 调用时机                             | 典型用途                    |
| --------------- | ------------------------------------ | --------------------------- |
| `onInit`        | 组件实例创建后，尚未挂载到 DOM       | 初始化数据、发起异步请求    |
| `onBeforeMount` | 即将挂载到 DOM 之前                  | 挂载前最后的准备工作        |
| `onShow`        | 组件显示时（首次挂载和从隐藏恢复时） | 启动动画、恢复定时器        |
| `onMounted`     | 挂载到 DOM 之后                      | 访问 DOM 元素、启动第三方库 |
| `onHide`        | 组件隐藏时                           | 暂停动画、暂停定时器        |
| `onDispose`     | 组件销毁时                           | 清理资源、取消订阅          |
| `onError`       | 组件内部发生异常时                   | 错误捕获与降级处理          |
| `onViewSwitch`  | 视图切换事务触发时                   | 过渡动画控制                |

## onInit — 初始化

`onInit` 在组件实例创建后立即调用，此时响应式数据已初始化，但组件尚未挂载到 DOM。

`onInit` 支持返回 Promise，当返回 Promise 时，外层的 `Suspense` 会等待其完成后再显示组件内容。

```tsx
import { ref, onInit } from 'vitarx'

function MyComponent() {
  const data = ref<string | null>(null)

  onInit(() => {
    // 初始化数据
    data.value = '初始化完成'
  })

  return <div>{data}</div>
}
```

## onBeforeMount — 挂载前

`onBeforeMount` 在组件即将挂载到 DOM 之前调用，此时组件还没有渲染到页面上。

```tsx
import { onBeforeMount } from 'vitarx'

function MyComponent() {
  onBeforeMount(() => {
    console.log('组件即将挂载到 DOM')
  })

  return <div>Hello</div>
}
```

## onShow — 显示

`onShow` 在组件显示时调用，包括两种场景：

1. 组件首次挂载到 DOM 时
2. 组件从隐藏状态恢复显示时（如 `v-show` 切换为 true）

```tsx
import { ref, onShow } from 'vitarx'

function MyComponent() {
  const timer = ref<number | null>(null)

  onShow(() => {
    // 组件可见时启动定时器
    console.log('组件已显示')
    timer.value = window.setInterval(() => {
      console.log('定时执行')
    }, 1000)
  })

  return <div>定时器运行中</div>
}
```

## onMounted — 挂载后

`onMounted` 在组件挂载到 DOM 之后调用，此时可以安全地访问 DOM 元素。

```tsx
import { useRef, onMounted } from 'vitarx'

function MyComponent() {
  const elRef = useRef<HTMLDivElement>()

  onMounted(() => {
    // 此时可以安全访问 DOM 元素
    if (elRef.value) {
      console.log('元素宽度：', elRef.value.offsetWidth)
    }
  })

  return <div ref={elRef}>Hello</div>
}
```

## onHide — 隐藏

`onHide` 在组件隐藏时调用，与 `onShow` 配对使用。当组件通过 `v-show` 等方式被隐藏时触发。

```tsx
import { ref, onShow, onHide } from 'vitarx'

function AnimatedBox() {
  const timer = ref<number | null>(null)

  onShow(() => {
    // 显示时启动动画
    timer.value = window.setInterval(() => {
      console.log('动画帧')
    }, 16)
  })

  onHide(() => {
    // 隐藏时暂停动画
    if (timer.value !== null) {
      clearInterval(timer.value)
      timer.value = null
    }
  })

  return <div>动画盒子</div>
}
```

## onDispose — 销毁

`onDispose` 在组件即将被销毁时调用，用于清理资源和取消订阅，防止内存泄漏。

```tsx
import { ref, onMounted, onDispose } from 'vitarx'

function ChatRoom(props: { roomId: string }) {
  const messages = ref<string[]>([])

  onMounted(() => {
    // 模拟加入聊天室
    console.log(`加入聊天室：${props.roomId}`)
  })

  onDispose(() => {
    // 组件销毁时离开聊天室，清理资源
    console.log(`离开聊天室：${props.roomId}`)
    messages.value = []
  })

  return <div>聊天室：{props.roomId}</div>
}
```

## onError — 错误处理

`onError` 用于捕获组件内部发生的异常，包括子组件抛出的错误。它接收两个参数：`error`（错误对象）和 `info`（错误信息，包含 `source` 来源和 `instance` 实例）。

返回 `false` 表示错误已被处理，阻止错误继续向上冒泡；不返回或返回其他值则错误会继续冒泡到父组件。

```tsx
import { onError, ref } from 'vitarx'

function SafeComponent() {
  const hasError = ref(false)

  onError((error, info) => {
    console.error('捕获到错误：', error)
    console.error('错误来源：', info.source)
    hasError.value = true
    // 返回 false 阻止错误继续冒泡
    return false
  })

  if (hasError.value) {
    return <div>组件出现异常，请刷新页面</div>
  }

  return <div>正常内容</div>
}
```

错误冒泡机制：如果当前组件的 `onError` 没有返回 `false`，错误会继续冒泡到父组件的 `onError`，直到到达应用级别的 `config.errorHandler`。

## onViewSwitch — 视图切换

`onViewSwitch` 用于监听组件内部 `Dynamic` 视图的切换事件，常用于实现过渡动画。

```tsx
import { onViewSwitch, ref } from 'vitarx'
import { Dynamic } from 'vitarx'

function TabContainer() {
  const currentTab = ref('home')

  onViewSwitch((tx) => {
    // tx.prev — 切换前的视图信息
    // tx.next — 切换后的视图信息
    console.log('视图切换：', tx.prev, '->', tx.next)

    // 可以配置缓存
    tx.cachePrev = true
  })

  return <Dynamic is={currentTab} />
}
```

> `onViewSwitch` 主要用于高级场景，如自定义过渡动画。日常开发中，推荐使用内置的 `Transition` 组件。

## 生命周期执行顺序

组件首次创建并挂载时的执行顺序：

```
组件函数执行
    │
    ▼
onInit（可返回 Promise，Suspense 会等待）
    │
    ▼
onBeforeMount
    │
    ▼
DOM 挂载
    │
    ▼
onShow ─── onMounted
```

组件隐藏和恢复显示：

```
组件隐藏时：onHide
组件恢复时：onShow
```

组件销毁：

```
onHide → onDispose
```

## 完整示例

下面是一个展示所有生命周期钩子的完整示例——一个带定时器的时钟组件：

```tsx
import { ref, onInit, onBeforeMount, onShow, onMounted, onHide, onDispose, onError } from 'vitarx'

function Clock() {
  const time = ref('')
  const tickCount = ref(0)
  let timer: number | null = null

  onInit(() => {
    // 初始化时间
    time.value = new Date().toLocaleTimeString()
    console.log('[Clock] 初始化完成')
  })

  onBeforeMount(() => {
    console.log('[Clock] 即将挂载')
  })

  onShow(() => {
    // 组件可见时启动定时器
    console.log('[Clock] 已显示，启动定时器')
    timer = window.setInterval(() => {
      time.value = new Date().toLocaleTimeString()
      tickCount.value++
    }, 1000)
  })

  onMounted(() => {
    console.log('[Clock] 已挂载到 DOM')
  })

  onHide(() => {
    // 组件隐藏时暂停定时器
    console.log('[Clock] 已隐藏，暂停定时器')
    if (timer !== null) {
      clearInterval(timer)
      timer = null
    }
  })

  onDispose(() => {
    // 组件销毁时清理资源
    console.log('[Clock] 已销毁，清理资源')
    if (timer !== null) {
      clearInterval(timer)
      timer = null
    }
  })

  onError((error, info) => {
    console.error('[Clock] 发生错误：', error, '来源：', info.source)
    return false // 阻止错误冒泡
  })

  return (
    <div class="clock">
      <h2>当前时间</h2>
      <p class="time">{time}</p>
      <p class="tick">已更新 {tickCount} 次</p>
    </div>
  )
}

// 使用时钟组件
function App() {
  const showClock = ref(true)

  return (
    <div>
      <button
        onClick={() => {
          showClock.value = !showClock.value
        }}
      >
        {showClock.value ? '隐藏' : '显示'}时钟
      </button>
      <div v-show={showClock}>
        <Clock />
      </div>
    </div>
  )
}
```
