# 异步组件

异步组件是指在组件的构造阶段，会有异步操作，比如请求数据，需要等待数据返回后才能渲染组件。在实际开发中，异步组件常用于以下场景：

- 数据依赖：组件渲染依赖于异步获取的数据
- 条件加载：根据条件动态加载组件
- 性能优化：将大型组件拆分成异步加载的小组件

## 定义异步组件

在 Vitarx 中，你可以通过以下两种方式定义异步组件：

### 使用 async 函数

最简单的方式是直接使用 `async` 关键字定义组件：

```tsx
interface UserInfo {
  id: string
  name: string
}

async function AsyncUserInfo(props: { id: string }) {
  // 使用 withAsyncContext 来保持上下文
  const data = await withAsyncContext<UserInfo>(() => 
    fetch(`/api/user/${props.id}`).then(res => res.json())
  )
  
  return <div>用户ID: {props.id}，用户名: {data.name}</div>
}
```

### 返回 Promise

你也可以直接返回一个 Promise：

```tsx
function AsyncComponent(props: { path: string }) {
  return withAsyncContext(() =>
    import(`./components/${props.path}.tsx`)
  ).then(module => {
    const Component = module.default
    return <Component {...props} />
  })
}
```

> 注意：在异步组件中进行异步操作时，必须使用 `withAsyncContext` 来保持上下文，否则会导致上下文丢失！

## 使用异步组件

Vitarx 允许你像使用普通组件一样直接使用异步组件：

```tsx
export default function App() {
  return (
    <div>
      <AsyncUserInfo id="123" />
    </div>
  )
}
```

框架会自动处理异步组件的加载状态。如果你想自定义加载状态或错误处理，可以配合 `Suspense` 组件使用：

```jsx
import { Suspense } from 'vitarx'

export default function App() {
  return (
    <div>
      <Suspense 
        fallback={<div>加载中...</div>}
        onError={(error, info) => (
          <div>加载失败：{error.message}</div>
        )}
      >
        <AsyncUserInfo id="123" />
      </Suspense>
    </div>
  )
}
```

## TypeScript 类型支持

为了在 TSX 中获得更好的类型推断支持，Vitarx 提供了 `defineAsyncWidget` 函数：

```tsx
import { defineAsyncWidget } from 'vitarx'

const AsyncUserInfo = defineAsyncWidget(async function(props: { id: string }) {
  const data = await withAsyncContext<UserInfo>(() => 
    fetch(`/api/user/${props.id}`).then(res => res.json())
  )
  return <div>用户ID: {props.id}，用户名: {data.name}</div>
})
```

`defineAsyncWidget` 的作用是提供正确的类型推断，让 TypeScript 能够正确识别异步组件的 props 类型。这在以下场景特别有用：

- 使用 TSX 语法时
- 需要严格的类型检查
- IDE 智能提示
