# RouterView拓展

`RouterView` 组件是路由视图渲染的核心组件，除了基本的路由视图渲染功能外，它还提供了一些强大的拓展特性。本文将介绍 `RouterView` 类组件的属性和方法，以及如何通过继承并重写 `build` 方法来实现页面级缓存。

## 属性和方法

### index

- 类型：`number`
- 说明：当前路由器视图所在层级索引，从0开始，与 `RouteLocation.matched` 数组下标一一对应

### isLastView

- 类型：`boolean`
- 说明：是否为最后一个路由视图，当 `index` 等于 `location.matched.length - 1` 且 `name` 为 'default' 时为 `true`

### name

- 类型：`string`
- 默认值：'default'
- 说明：视图名称，用于命名视图功能

### matchedRoute

- 类型：`ReadonlyRouteNormalized | undefined`
- 说明：当前匹配的路线配置，未匹配时返回 `undefined`

### currentElement

- 类型：`VNode<WidgetType> | undefined`
- 说明：当前路由器视图要显示的虚拟节点，未匹配时返回 `undefined`
- 访问权限：protected

### currentWidget

- 类型：`WidgetType | undefined`
- 说明：当前路由器视图要显示的组件
- 访问权限：protected

### location

- 类型：`RouteLocation`
- 说明：当前的路由位置对象
- 访问权限：protected

## 页面缓存

在单页应用中，频繁的页面切换会导致组件的重复创建和销毁，这不仅会影响性能，还会丢失页面状态。通过继承 `RouterView` 类组件并结合 `KeepAlive` 组件，我们可以实现页面级缓存，保持页面状态并提升性能。

### 基本用法

```tsx
import { RouterView, KeepAlive } from 'vitarx'

// 创建一个继承自RouterView的类组件
class CacheRouterView extends RouterView {
  build() {
    // 重写build方法，在路由视图外层包裹KeepAlive组件
    // 使用this.currentElement获取当前要渲染的虚拟DOM节点
    if (!this.currentElement) return null
    return (
      <KeepAlive>
        {this.currentElement}
      </KeepAlive>
    )
  }
}

export default function App() {
  return (
    <div>
      <CacheRouterView />
    </div>
  )
}
```

### 控制缓存范围

你可以通过 `include` 和 `exclude` 属性精确控制需要缓存的页面组件：

```tsx
import { RouterView, KeepAlive } from 'vitarx'

class CacheRouterView extends RouterView {
  build() {
    if (!this.currentElement) return null
    // include 和 exclude 通常只需要其中之一，这里同时设置只是为了示例演示
    return (
      <KeepAlive 
        include={[HomePage, UserProfile]} 
        exclude={[LoginPage]}
      >
        {this.currentElement}
      </KeepAlive>
    )
  }
}

export default function App() {
  return (
    <div>
      <CacheRouterView />
    </div>
  )
}
```

### 缓存控制

为了避免缓存占用过多内存，你可以设置最大缓存数量：

```tsx
class CacheRouterView extends RouterView {
  build() {
    if (!this.currentElement) return null
    return (
      <KeepAlive max={10}>
        {this.currentElement}
      </KeepAlive>
    )
  }
}
```

## 最佳实践

1. **选择性缓存**
   - 只缓存真正需要保持状态的页面
   - 避免缓存包含大量动态数据的页面
   - 登录页面等状态敏感的页面建议不要缓存

2. **性能优化**
   - 合理设置最大缓存数量
   - 使用 `include` 和 `exclude` 精确控制缓存范围

3. **注意事项**
   - 继承 `RouterView` 时确保正确重写 `build` 方法
   - 被缓存的页面组件生命周期会被保持
   - 确保缓存的页面不会造成内存泄漏
   - 需要注意缓存页面中的副作用清理
