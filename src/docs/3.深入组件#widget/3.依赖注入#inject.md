# 依赖注入

依赖注入（Dependency Injection）是一种在组件之间传递数据的方式。

它特别适用于需要将数据从父组件传递到深层嵌套的子组件的场景，避免了通过 props 层层传递（也称为 "prop 逐级透传"）的麻烦。

## 基础用法

```jsx
import {inject, provide} from 'vitarx'

function Test() {
  return <div>{inject('message')}</div>
}

function App() {
  provide(/* 注入名 */ 'message', /* 值 */ 'hello!')
  return <Test />
}
```

## 注入默认值

当提供的注入值可能不存在时，我们可以为 inject 设置一个默认值：

```jsx
function Test() {
  // 如果没有提供值，则使用默认值
  const msg = inject('message', 'default value')
  return <div>{msg}</div>
}
```

## 响应式注入

如果我们想让注入的值是响应式的，可以注入一个 ref：

```jsx
import {inject, provide, ref} from 'vitarx'

function Test() {
  const count = inject('count')
  return <div>当前计数：{count.value}</div>
}

function App() {
  const count = ref(0)
  
  provide('count', count)
  
  return (
    <div>
      <button onClick={() => count.value++}>增加</button>
      <Test />
    </div>
  )
}
```

## 作用域规则

provide/inject 遵循单向数据流原则。父组件可以向任意后代组件注入数据，但是子组件不能修改父组件注入的数据。这有助于维护应用的数据流向，使其更可预测。

```jsx
function GrandChild() {
  const theme = inject('theme')
  return <div style={{ color: theme.value }}>我是孙组件</div>
}

function Child() {
  return <GrandChild />
}

function App() {
  const theme = ref('blue')
  provide('theme', theme)
  
  return (
    <div>
      <button onClick={() => theme.value = theme.value === 'blue' ? 'red' : 'blue'}>
        切换主题
      </button>
      <Child />
    </div>
  )
}
```

## 最佳实践

1. **适度使用**：依赖注入虽然方便，但会使数据流向变得不那么明显。对于大型应用，应当拥有独立的`全局状态管理`。

2. **命名规范**：使用清晰地注入名称，建议使用 Symbol 作为注入名以避免命名冲突：

    ```js
    const themeSymbol = Symbol('theme')
    
    function App() {
      provide(themeSymbol, ref('dark'))
      // ...
    }
    
    function Child() {
      const theme = inject(themeSymbol)
      // ...
    }
    ```

3. **类型安全**：在 TypeScript 项目中，建议为注入值定义明确的类型：

    ```ts
    interface ThemeData {
      color: string
      size: number
    }
    
    const theme = inject<ThemeData>('theme')
    ```

4. **文档化**：由于依赖注入创建了隐式的依赖关系，建议在组件文档中明确说明组件依赖的注入内容。
