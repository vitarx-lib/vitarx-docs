# 内置组件

Vitarx 提供了一系列开箱即用的内置组件，帮助你处理异步加载、列表渲染、组件缓存、动态渲染、内容传送、过渡动画等常见场景。

## 组件列表

| 组件                            | 说明                                               |
| ------------------------------- | -------------------------------------------------- |
| [Suspense](./1.suspense.md)     | 异步内容占位，在子组件加载完成前显示 fallback 内容 |
| [For](./2.for.md)               | 列表渲染，支持 key 优化、列表动画钩子              |
| [Freeze](./3.freeze.md)         | 组件缓存/冻结，切换时保留组件状态而非销毁          |
| [Lazy / lazy](./4.lazy.md)      | 惰性加载组件，支持延迟显示、超时、错误处理         |
| [Dynamic](./5.dynamic.md)       | 动态组件/元素渲染，支持缓存策略                    |
| [Teleport](./6.teleport.md)     | 将内容传送到 DOM 中的其他位置（如模态框、通知）    |
| [Transition](./7.transition.md) | CSS 过渡动画，支持进入/离开动画和列表过渡          |
| [Head](./8.head.md)             | 管理 document head，用于设置页面标题、meta 信息等  |
