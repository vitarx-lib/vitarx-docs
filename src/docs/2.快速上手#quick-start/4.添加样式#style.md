# 添加样式

在 Vitarx 中 你可以使用 `className` 或 `class` 来指定 CSS 类名，使用 `style` 指定内联样式。

## 指定CSS类名

class 属性值支持多种类型：

- **字符串**：字符串是符合 W3C CSS 规范定义的类名，多个类名用空格分隔。
- **数组**：可以用数组来指定多个类名。
- **对象**：对象的键是CSS类名，值如果为“假”则不会被附加给元素。

```jsx
// 通过import导入样式文件
import '@/assets/style.css';

function App() {
  return <>
    {/*使用 class*/}
    <img class="my-class" />
    {/*使用 className*/}
    <img className="my-class" />
    {/*使用数组做为值*/}
    <img class={['my-class', 'my-class2']} />
    {/*使用对象做为值*/}
    <img class={{ 'my-class': true, 'active': false }} />
    {/*重复使用className或class属性，将会自动合并*/}
    <img className="my-class" class="my-class2" />
  </>
}
```

## 指定style内联样式

style 属性支持多种类型：

- **字符串**：字符串是符合 W3C CSS 规范定义的样式。
- **对象**：对象的键是CSS样式名，值是样式值。

```jsx
<img style="color: red;" />
<img style={{ color: 'red' }} />
```


## CssInJs解决方案

Vitarx 提供了 [CssInJs](https://github.com/vitarx-lib/css-in-js) 解决方案，你可以使用它来编写 CSS-in-JS 代码。
