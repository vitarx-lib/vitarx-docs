# 指令系统

指令是 Vitarx 中一种特殊的机制，用于在元素挂载、更新或销毁时执行自定义逻辑。你可以把指令理解为"挂在元素上的钩子"——当元素的状态发生变化时，指令中对应的钩子函数会被自动调用。

## 内置指令

Vitarx 提供了以下内置指令，覆盖了最常见的 DOM 操作需求：

| 指令                                                                | 说明                                    |
| ------------------------------------------------------------------- | --------------------------------------- |
| [v-show](./1.builtin.md#v-show)                                     | 控制元素的显示与隐藏（`display: none`） |
| [v-html](./1.builtin.md#v-html)                                     | 渲染 HTML 字符串到元素内部              |
| [v-text](./1.builtin.md#v-text)                                     | 设置元素的文本内容                      |
| [v-if / v-else-if / v-else](./1.builtin.md#v-if--v-else-if--v-else) | 条件渲染指令                            |
| [v-bind](./1.builtin.md#v-bind)                                     | 属性展开绑定                            |

👉 [查看内置指令详情](./1.builtin.md)

## 自定义指令

当内置指令无法满足需求时，你可以编写自定义指令。自定义指令适合封装直接操作 DOM 的逻辑，例如自动聚焦、权限控制、拖拽等。

| API                  | 说明                |
| -------------------- | ------------------- |
| `defineDirective()`  | 定义指令            |
| `withDirectives()`   | 为视图手动绑定指令  |
| `resolveDirective()` | 根据名称解析指令    |
| `app.directive()`    | 应用级指令注册/获取 |

👉 [查看自定义指令详情](./2.custom.md)
