# 编写组件

`Vitarx` 支持使用 `JSX` 模板语法编写组件，也可以使用 `createElement` API函数创建虚拟节点的方式，但推荐使用 `JSX` 语法。

## 类组件

类组件必须继承自 `Widget` 类，并实现 `build` 方法：

```jsx
import { Widget } from 'vitarx';

export default class App extends Widget {
  build() {
    return <div>Hello World</div>;
  }
}
```

## 函数组件

为了适应函数式编程体验，Vitarx 也支持通过函数定义组件：

```jsx
// 定义一个函数组件
export default function App() {
  return <div>Hello World</div>;
}
// 上面的示例代码会被编译为：
export default function App() {
  return () => jsx('div', null, 'Hello World');
}
```

可以从编译结果中发行，不光是将 `div` 节点使用 `jsx` 函数创建虚拟节点，且添加了箭头函数返回虚拟节点。

这样做是为了将视图和逻辑层分离，组件状态变化时只会重新执行这个箭头函数得到新的节点对象，而不会重新执行整个组件函数，

但打包器语法分析存在一些难以覆盖完全的边界情况。

具体请看下面的示例：

```jsx
import { ref,build } from 'vitarx'

export default function App(props) {
  // ❌ 这是一个错误的示例，因为打包器不会分析三元运算符，所以 props.show 值变化时视图并不会被更新，除非你不希望它被更新。
  return props.show ? <div>Hello World</div> : <div>Hello Vitarx</div>
  
  // ✅ 正确的写法；可以不使用build函数包裹，build函数是为了优化TSX语法校验，也可以让代码更加清晰。
  return build(()=>props.show ? <div>Hello World</div> : <div>Hello Vitarx</div>)
}
```

## 组件参数

组件可以通过 `props` 参数/属性获取外部传入的所有参数，`props` 是一个浅层响应式只读对象：

```jsx
export default function App(props) {
  return <div>Hello {props.name}</div>;
}

// 以下是类组件的写法

import { Widget } from 'vitarx';

export default class App extends Widget {
  build() {
    // this.props 是外部传入给组件的参数
    return <div>Hello {this.props.name}</div>;
  }
}
```

tsx 语法支持类型提示，可以定义 props 的类型：

```tsx
interface Props {
  name: string
}

function App(props: Props) {
  return <div>Hello {props.name}</div>;
}

// 类组件的写法
class App extends Widget<Props> {
  build() {
    return <div>Hello {this.props.name}</div>;
  }
}
```

详细的 props 说明请查看 [深入组件参数](/docs/widget/props)。

## 特殊参数children

组件存在一个特殊的 `children` 参数，用于接收组件的子节点：

```jsx
function Test(props) {
  // props.children 有可能是数组，也有可能是字符串，数字等类型，如果传入多个子节点则会是数组
  // 可以直接在视图中直接渲染传入的节点，它是具备响应性的，如果在父组件中修改了子节点，子组件也会更新
  return <div>{props.children}</div>;
}

export default function App() {
  return <div>
    <Test>
      {/*在Test组件中可以通过props.children获得传入的子节点*/}
      <p>Hello World</p>
    </Test>
  </div>
}
```

> 注意：`children` 是固定地命名，它可以通过插槽传入，也可以通过属性传入。

更详细的 `children` 参数说明请查看 [深入组件children](/docs/widget/children)。
