# 计算属性

计算属性是基于响应式依赖进行缓存的特殊值。当依赖的响应式状态发生变化时，计算属性会自动重新计算并更新结果。这使得我们可以声明性地描述一个值依赖于其他值的方式。

## 基本概念

计算属性具有以下特点：

- **响应式**：自动追踪依赖并在依赖变化时更新
- **缓存**：基于依赖缓存计算结果，避免不必要的重复计算
- **只读性**：默认为只读，需要时可配置为可写
- **惰性计算**：默认情况下只在被访问时才计算

## 基础用法

使用 `computed()` 函数创建计算属性：

```js
import { ref, computed } from 'vitarx'

const count = ref(0)
const double = computed(() => count.value * 2)
```
