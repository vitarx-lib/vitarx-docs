# Children

`children` 类似于 vue 的插槽，是 Vitarx 中用于接收和渲染子节点的特殊参数。在 JSX 编译过程中，组件的子节点会被转换为 `props.children` 参数。

## 基本用法

在 JSX 中，组件的子节点可以是任意类型的内容，包括文本、数字、JSX 元素或者它们的数组：

```jsx
function Container(props) {
  return <div className="container">{props.children}</div>;
}

// 使用示例
function App() {
  return (
    <Container>
      <h1>标题</h1>
      <p>这是一段文本</p>
    </Container>
  );
}
```

## JSX 编译原理

当 JSX 代码被编译时，子节点会被转换为 `props.children` 参数。上面的示例会被编译为类似这样的代码：

```js
function Container(props) {
  return jsx('div', { className: 'container' }, props.children);
}

function App() {
  return jsx(Container, null, [
    jsx('h1', null, '标题'),
    jsx('p', null, '这是一段文本')
  ]);
}
```

## children 类型

`props.children` 可能有以下几种类型：

1. **单个子节点**：直接是一个节点对象
2. **多个子节点**：节点对象数组
3. **文本内容**：字符串或数字
4. **空内容**：null 或 undefined

```jsx
import { build } from 'vitarx';
// 处理不同类型的 children
function MultiPurposeContainer(props) {
  return build(() => {
    // 判断 children 类型
    if (Array.isArray(props.children)) {
      return <div className="multi">{props.children}</div>;
    }
    
    if (typeof props.children === 'string' || typeof props.children === 'number') {
      return <div className="text">{props.children}</div>;
    }
    
    if (props.children === null || props.children === undefined) {
      return <div className="empty">暂无内容</div>;
    }
    
    return <div className="single">{props.children}</div>;
  });
}
```

## 条件渲染

可以在父组件中通过条件语句控制子节点的渲染：

```jsx
function ConditionalContainer(props) {
  return (
    <div>
      {props.showHeader && <header>{props.children[0]}</header>}
      <main>{props.children[1]}</main>
      {props.showFooter && <footer>{props.children[2]}</footer>}
    </div>
  );
}

function App() {
  return (
    <ConditionalContainer showHeader={true} showFooter={false}>
      <div>页头内容</div>
      <div>主要内容</div>
      <div>页脚内容</div>
    </ConditionalContainer>
  );
}
```

## 与 Vue 插槽的区别

虽然 `children` 和 Vue 的插槽概念类似，但有以下区别：

1. Vue 的插槽可以有具名插槽，而 Vitarx 的 children 是按数组索引访问
2. Vue 的插槽可以传递数据给子组件（作用域插槽），而 Vitarx 需要通过 props 或其他方式传递数据
3. Vitarx 的 children 更接近 React 的实现方式，更适合函数式编程思维

通过合理使用 children 参数，可以创建更灵活和可复用的组件。记住要注意性能优化，避免不必要的重渲染。
