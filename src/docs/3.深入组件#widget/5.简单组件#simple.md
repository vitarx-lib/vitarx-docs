# 简单组件

简单组件是一种特殊的组件类型，它专注于纯粹的视图渲染，没有生命周期和状态管理能力。在 Vitarx 中，你可以使用 `simple` 函数来定义一个简单组件。

## 什么是简单组件

简单组件是一种轻量级的组件，它具有以下特点：

- **无生命周期**：简单组件没有生命周期钩子，不能使用 `onMounted`、`onUnmounted` 等钩子函数
- **无状态管理**：简单组件内部不应使用状态管理相关的 API，如 `ref`、`reactive` 等
- **无副作用**：简单组件内部不应该有任何副作用代码，如定时器、事件监听器等
- **纯函数**：简单组件本质上是一个纯函数，接收 props 并返回视图

## 使用场景

简单组件通常用于以下场景：

- **UI 组件库**：大多数 UI 组件库中的组件只需要提供样式和基本交互，不需要复杂的状态管理
- **展示型组件**：只负责展示数据，不需要管理状态的组件
- **性能优化**：当你需要频繁重渲染的组件，使用简单组件可以避免不必要的生命周期执行

## 定义简单组件

使用 `simple` 函数来定义一个简单组件：

```tsx
import { simple } from 'vitarx'

interface Props {
  title: string
  color?: string
}

// 定义一个简单组件
const Title = simple(({color = 'black'}: Props) => {
  // 简单组件的props可以解构，因为简单组件本就不具备状态
  // 返回需要渲染的元素
  return <h1 style={{ color }}>{props.title}</h1>
})

// 在其他组件中使用
export default function App() {
  return <Title title="Hello Vitarx" color="red" />
}
```

## 简单组件与普通组件的区别

| 特性   | 简单组件          | 普通组件         |
|------|---------------|--------------|
| 生命周期 | ❌ 不支持         | ✅ 支持         |
| 状态管理 | ❌ 不支持         | ✅ 支持         |
| 副作用  | ❌ 不支持         | ✅ 支持         |
| 渲染时机 | 父组件每次更新都会重新调用 | 根据依赖决定是否重新渲染 |
| 适用场景 | 纯展示型组件        | 复杂交互组件       |

## 注意事项

- 简单组件在父组件首次构建视图时被调用，在父组件更新时会被重新调用
- 简单组件内部不要使用任何副作用代码，包括但不限于：生命周期钩子、定时器、监听器、计算属性等
- 简单组件适合用于纯展示型组件，如果需要状态管理或生命周期，请使用普通组件
- 简单组件的性能优势主要体现在避免了生命周期钩子的执行和状态管理的开销

## 判断是否为简单组件

Vitarx 提供了 `isSimpleWidget` 函数来判断一个组件是否为简单组件：

```tsx
import { isSimpleWidget } from 'vitarx'

const MyComponent = simple(() => <div>Hello</div>)

console.log(isSimpleWidget(MyComponent)) // true
```
