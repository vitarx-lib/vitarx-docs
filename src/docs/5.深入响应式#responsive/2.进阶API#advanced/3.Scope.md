# Scope

作用域管理器（Scope）是VitaRx中的一个核心概念，它主要用于管理组件和响应式对象的生命周期。通过作用域管理器，我们可以实现自动清理和资源回收，避免内存泄漏。

## 基本概念

作用域管理器主要负责：

1. 管理副作用对象的生命周期
2. 提供作用域上下文
3. 自动清理资源

## 创建作用域

### 使用构造函数

```ts
import { Scope } from 'vitarx'

// 创建一个基本的作用域
const scope = new Scope()

// 创建一个带配置的作用域
const namedScope = new Scope({
  name: 'MyScope',      // 作用域名称，方便调试
  toParent: true,       // 是否添加到父级作用域
  errorHandler: (e) => { // 处理副作用抛出的异常
    console.error(e)
  }
})
```

### 使用工厂函数

```ts
import { createScope } from 'vitarx'

const scope = createScope({
  name: 'MyScope',
  toParent: true
})
```

## 作用域上下文

作用域管理器提供了一个上下文环境，可以通过`run`方法在特定作用域中执行代码：

```ts
const scope = new Scope()

scope.run(() => {
  // 这里的代码会在scope作用域中执行
  // 所有在这个作用域中创建的响应式对象都会被这个作用域管理
})
```

### 异步上下文

在异步函数中使用作用域时，需要特别注意使用`withAsyncContext`来维护上下文：

```ts
import { Scope, withAsyncContext } from 'vitarx'

const scope = new Scope()

scope.run(async () => {
  // 使用withAsyncContext维护异步操作的上下文
  const result = await withAsyncContext(async () => {
    await someAsyncOperation()
    return 'result'
  })

  // 如果不使用withAsyncContext，在await之后的代码将失去作用域上下文
  // 这可能导致资源无法被正确管理和清理
})
```

## 自动处置

VitaRx提供了`AutoDisposed`类，继承自该类的实例会自动添加到当前作用域中进行管理：

```ts
import { AutoDisposed } from 'vitarx'

class MyResource extends AutoDisposed {
  constructor() {
    super()
    // 实例会自动添加到当前作用域
  }

  destroy() {
    // 清理资源
    super.destroy()
  }
}

scope.run(() => {
  const resource = new MyResource()
  // resource会在作用域销毁时自动清理
})
```

## API参考

### Scope类

#### 属性

- `name: string | symbol` - 作用域名称
- `count: number` - 当前作用域管理的副作用数量

#### 方法

- `run<T>(fn: () => T): T` - 在作用域中执行函数
- `add(effect: EffectInterface): boolean` - 添加副作用到作用域
- `destroy()` - 销毁作用域及其管理的所有副作用
- `pause()` - 暂停所有副作用
- `unpause()` - 恢复所有副作用

### 工具函数

- `createScope(options?: ScopeOptions): Scope` - 创建作用域
- `getCurrentScope(): Scope | undefined` - 获取当前作用域
- `useCurrentScope(): Scope | undefined` - getCurrentScope的别名
- `addEffect(effect: EffectInterface): boolean` - 添加副作用到当前作用域

## 最佳实践

1. 在组件中使用作用域时，不要手动销毁组件的作用域，这会由框架自动处理。

2. 在异步操作中始终使用`withAsyncContext`来维护作用域上下文：

```ts
scope.run(async () => {
  // ✅ 正确用法
  await withAsyncContext(async () => {
    await someAsyncOperation()
  })

  // ❌ 错误用法 - await后将丢失作用域上下文
  await someAsyncOperation()
})
```

3. 使用`AutoDisposed`类来自动管理资源的生命周期：

```ts
class CustomResource extends AutoDisposed {
  constructor() {
    super()
    // 初始化资源
  }

  destroy() {
    // 清理资源
    super.destroy()
  }
}
```

4. 合理使用错误处理：

```ts
const scope = new Scope({
  errorHandler: (error) => {
    console.error('Scope error:', error)
    // 进行错误处理
  }
})
```

通过合理使用作用域管理器，我们可以更好地管理应用中的资源和副作用，确保它们能够在适当的时候被正确清理，从而避免内存泄漏和其他资源管理问题。
