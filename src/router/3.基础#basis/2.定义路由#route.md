# 定义路由

## 基本路由

使用 `defineRoutes` 函数定义路由规则：

```js
import { defineRoutes } from 'vitarx-router'
import HomePage from './pages/Home'
import AboutPage from './pages/About'

const routes = defineRoutes(
  {
    path: '/',
    widget: HomePage
  },
  {
    path: '/about',
    widget: AboutPage
  }
)
export default routes
```

## 命名路由

为路由添加 `name` 属性以命名路由：

```js
defineRoutes(
  {
    path: '/',
    name: 'home',
    widget: HomePage
  },
  {
    path: '/about',
    name: 'about',
    widget: AboutPage
  }
)
```

## 动态路由

支持在路径中使用参数来创建动态路由：

```js
defineRoutes(
  {
    path: '/user/{id}',
    widget: UserPage
  },
  {
    // 支持多个参数
    path: '/posts/{category}/{id}',
    widget: PostPage
  },
  {
    // 支持可选参数
    path: '/posts/{category}/{id?}',
    // ...
  }
)
```

## 路由懒加载

```js
import { defineRoutes } from 'vitarx-router'

const routes = defineRoutes(
  {
    path: '/dashboard',
    widget: () => import('./pages/Dashboard')
  }
)
```

## 嵌套路由

通过 `children` 属性定义嵌套路由：

```js
defineRoutes(
  {
    path: '/user',
    widget: UserLayout,
    children: [
      {
        path: '/profile',  // 将被解析为 /user/profile
        widget: UserProfile
      },
      {
        path: '/settings', // 将被解析为 /user/settings
        widget: UserSettings
      }
    ]
  }
)
```

## 路由元信息

可以为路由添加自定义的元信息：

```js
defineRoutes(
  {
    path: '/admin',
    name: 'admin',
    widget: AdminPage,
    meta: {
      requiresAuth: true,
      roles: ['admin']
    }
  }
)
```

## 命名视图

命名视图允许在同一个路由下同时展示多个组件。通过在 `widget` 属性中使用对象形式，可以定义不同视图位置的组件。在使用命名视图时，必须包含一个默认视图（default），它作为主要内容区域的渲染组件：

```js
defineRoutes(
  {
    path: '/',
    widget: {
      default: HomePage,      // 默认视图，必须指定
      sidebar: SidebarWidget,
      navbar: NavbarWidget
    }
  }
)
```

在布局组件中，使用 `<RouterView>` 组件的 `name` 属性来渲染对应的视图：

```jsx
function Layout() {
  return (
    <div>
      <RouterView name="navbar" />
      <div className="content">
        <RouterView name="sidebar" />
        <RouterView /> {/* default 视图 */}
      </div>
    </div>
  )
}
```

也可以在嵌套路由中使用命名视图：

```js
defineRoutes(
  {
    path: '/settings',
    widget: SettingsLayout,
    children: [
      {
        path: '/profile',
        widget: {
          default: UserProfile,    // 嵌套路由中同样需要指定默认视图
          helper: ProfileHelper
        }
      }
    ]
  }
)
```

## 路由配置详解

路由配置对象包含以下属性：

### path

- **类型**：`string`
- **必填**：是

路由的URL匹配路径。支持动态路径参数和可选参数：

```js
defineRoutes(
  {
    // 静态路径
    path: '/about'
  },
  {
    // 动态参数
    path: '/user/{id}'
  },
  {
    // 可选参数
    path: '/posts/{category}/{id?}'
  }
)
```

### pattern

- **类型**：`Record<string, RegExp>`
- **可选**：是

定义动态路由参数的匹配模式。默认继承自路由器配置：

```js
defineRoutes({
  path: '/user/{id}',
  // 限制id只能是数字
  pattern: {
    id: /^\d+$/
  }
})
```

### name

- **类型**：`string`
- **可选**：是

路由的唯一标识名称，用于编程式导航：

```js
defineRoutes({
  path: '/user/{id}',
  name: 'user-profile'
})

// 使用名称导航
router.push({ name: 'user-profile', params: { id: '123' } })
```

### widget

- **类型**：`Component | Record<string, Component> | () => Promise<Component>`
- **可选**：是

指定路由对应的视图组件。支持以下形式：

```js
// 直接指定组件
defineRoutes({
  path: '/home',
  widget: HomePage
})

// 命名视图
defineRoutes({
  path: '/settings',
  widget: {
    default: SettingsPage,
    sidebar: SettingsSidebar
  }
})

// 懒加载
defineRoutes({
  path: '/admin',
  widget: () => import('./pages/Admin')
})
```

### redirect

- **类型**：`string | RouteLocation | ((to: RouteLocation) => RouteTarget)`
- **可选**：是

指定路由重定向目标：

```js
// 字符串路径
defineRoutes({
  path: '/home',
  redirect: '/dashboard'
})

// 路由位置对象
defineRoutes({
  path: '/home',
  redirect: { name: 'dashboard' }
})

// 动态重定向
defineRoutes({
  path: '/search',
  redirect: to => {
    return { path: '/results', query: to.query }
  }
})
```

### children

- **类型**：`Route[]`
- **可选**：是

定义嵌套路由配置：

```js
defineRoutes({
  path: '/user',
  widget: UserLayout,
  children: [
    {
      path: '/profile',
      widget: UserProfile
    },
    {
      path: '/settings',
      widget: UserSettings
    }
  ]
})
```

### meta

- **类型**：`Record<string, any>`
- **可选**：是

路由的元数据，用于存储自定义信息：

```js
defineRoutes({
  path: '/admin',
  meta: {
    requiresAuth: true,
    roles: ['admin']
  }
})
```

### suffix

- **类型**：`'*' | string | string[] | false`
- **可选**：是

配置路由路径的后缀匹配规则：

```js
defineRoutes(
  {
    // 匹配任意后缀
    path: '/docs',
    suffix: '*'
  },
  {
    // 匹配指定后缀
    path: '/api',
    suffix: '.json'
  },
  {
    // 匹配多个后缀
    path: '/posts',
    suffix: ['.html', '.md']
  },
  {
    // 禁用后缀匹配
    path: '/exact',
    suffix: false
  }
)
```

### injectProps

- **类型**：`boolean | Record<string, any> | (location: RouteLocation) => Record<string, any>`
- **默认值**：`true`

配置路由组件的参数注入：

```js
defineRoutes(
  {
    // 注入动态参数
    path: '/user/{id}',
    injectProps: true
  },
  {
    // 禁用参数注入
    path: '/about',
    injectProps: false
  },
  {
    // 静态参数
    path: '/settings',
    injectProps: {
      title: '系统设置'
    }
  },
  {
    // 动态计算参数
    path: '/posts/{id}',
    injectProps: location => ({
      id: location.params.id,
      timestamp: Date.now()
    })
  },
  {
    // 命名视图的参数注入
    path: '/dashboard',
    widget: {
      default: Dashboard,
      sidebar: Sidebar
    },
    injectProps: {
      default: { title: '仪表盘' },
      sidebar: { collapsed: false }
    }
  }
)
```

### beforeEnter

- **类型**：`(to: RouteLocation, from: RouteLocation) => Promise<boolean | void> | boolean | void`
- **可选**：是

路由进入前的守卫函数：

```js
defineRoutes({
  path: '/admin',
  beforeEnter: (to, from) => {
    // 检查用户权限
    if (!isAuthenticated()) {
      return false // 取消导航
    }
    // 允许导航
    return true
  }
})
```

### afterEnter

- **类型**：`(to: RouteLocation, from: RouteLocation) => void`
- **可选**：是

路由进入后的回调函数：

```js
defineRoutes({
  path: '/article/{id}',
  afterEnter: (to, from) => {
    // 记录访问日志
    logPageView(to.params.id)
  }
})
```
