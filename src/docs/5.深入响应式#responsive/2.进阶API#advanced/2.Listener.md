# Listener

`Listener` 是一个强大的监听器类，用于处理回调函数的触发和生命周期管理。它继承自 `Effect` 类，提供了灵活的配置选项和完善的监听机制。

## 创建监听器

使用 `new Listener()` 构造函数创建监听器实例。构造函数接受两个参数：
- `callback`: 监听回调函数
- `options`: 配置选项对象

```js
import { Listener } from 'vitarx'

// 创建一个基本的监听器
const listener = new Listener((value) => {
  console.log('Value changed:', value)
})

// 使用配置选项创建监听器
const limitedListener = new Listener((value) => {
  console.log('Value changed:', value)
}, {
  limit: 3,    // 限制触发3次
  scope: true  // 自动添加到作用域
})
```

## 配置选项

### limit

`limit` 选项用于限制监听器的触发次数：
- 默认值为 `0`，表示无限制
- 设置为正整数时，监听器最多触发指定次数后会自动销毁

```js
// 创建只触发3次的监听器
const listener = new Listener((value) => {
  console.log('Triggered:', value)
}, { limit: 3 })

// 触发监听器
listener.trigger([1]) // 输出: Triggered: 1
listener.trigger([2]) // 输出: Triggered: 2
listener.trigger([3]) // 输出: Triggered: 3
listener.trigger([4]) // 不会触发，监听器已销毁
```

### scope

`scope` 选项控制监听器是否自动添加到当前作用域：
- 默认值为 `true`，监听器会随作用域销毁而自动销毁
- 设置为 `false` 时需要手动管理监听器的生命周期

```js
// 创建不自动添加到作用域的监听器
const listener = new Listener((value) => {
  console.log('Value:', value)
}, { scope: false })
```

## 监听器状态

### count

`count` 属性返回监听器已触发的次数：

```js
const listener = new Listener((value) => {
  console.log('Triggered:', value)
})

listener.trigger([1])
listener.trigger([2])
console.log(listener.count) // 输出: 2
```

### limit

`limit` 属性返回监听器的触发次数限制：

```js
const listener = new Listener((value) => {
  console.log('Value:', value)
}, { limit: 5 })

console.log(listener.limit) // 输出: 5
```

## 生命周期管理

### destroy()

`destroy()` 方法用于销毁监听器：
- 销毁后的监听器无法再次触发
- 销毁操作会清除回调函数引用

```js
const listener = new Listener((value) => {
  console.log('Value:', value)
})

listener.trigger([1]) // 输出: Value: 1
listener.destroy()
listener.trigger([2]) // 不会触发
```

### resetCount()

`resetCount()` 方法用于重置监听器的触发次数：
- 重置后可以重新开始计数
- 如果监听器已销毁，则返回 `false`

```js
const listener = new Listener((value) => {
  console.log('Value:', value)
}, { limit: 2 })

listener.trigger([1]) // 输出: Value: 1
listener.trigger([2]) // 输出: Value: 2

// 重置计数
if (listener.resetCount()) {
  listener.trigger([3]) // 输出: Value: 3
  listener.trigger([4]) // 输出: Value: 4
}
```

## 触发监听器

### trigger()

`trigger()` 方法用于触发监听器的回调函数：
- 接受与回调函数相同的参数列表
- 返回 `boolean` 值表示监听器是否仍然活跃
- 以下情况不会触发回调：
  - 监听器已销毁
  - 监听器已暂停
  - 已达到触发次数限制

```js
const listener = new Listener((value, type) => {
  console.log(`${type}: ${value}`)
})

// 触发监听器
listener.trigger('Hello', 'message') // 输出: message: Hello

// 检查触发结果
const isActive = listener.trigger('World', 'update')
console.log('Listener is active:', isActive) // 输出: Listener is active: true
```
