# 导航

## RouterLink

`RouterLink`组件是一个用于路由导航的组件，它会渲染一个`<a>`标签，点击后会跳转到目标路由。

#### to

`to`属性用于指定导航的目标，它支持多种形式：

- **路由目标对象**：一个包含路由信息的对象，可以指定路由索引、hash、查询参数等
  ```ts
  interface RouteTarget {
    // 路由索引，/开头为路径，否则为名称
    index: RouteIndex
    // URL hash
    hash?: HashStr
    // URL 查询参数
    query?: Record<string, string>
    // 路由参数
    params?: Record<string, any>
    // 是否替换当前路由
    isReplace?: boolean
  }
  ```
- **命名路由**：不以`/`开头的字符串，表示路由的名称
- **路由路径**：以`/`开头的字符串，表示路由的路径
- **HTTP链接**：以`http://`或`https://`开头的字符串，表示外部链接
- **Hash**：以`#`开头的字符串，表示页面内锚点
- **路径Hash组合**：以`/`开头，包含`#`的字符串，表示路由路径和hash的组合

示例：
```ts
// 路由目标对象
<RouterLink to={{ index: '/home', hash: '#top' }} />

// 命名路由
<RouterLink to="home" />

// 路由路径
<RouterLink to="/home" />

// HTTP链接
<RouterLink to="https://example.com" />

// Hash
<RouterLink to="#top" />

// 路径Hash组合
<RouterLink to="/home#top" />
```

#### active

`active`属性用于配置激活状态的计算方式，当路由匹配到当前路由时，`<a>`标签会添加`aria-current="page"`属性。

可选值：
- `'none'`：不计算激活状态（默认值）
- `'obscure'`：模糊匹配，只要目标路由的路径以当前路由的路径开头，就认为当前路由处于激活状态
- `'strict'`：严格匹配，只有目标路由的路径完全匹配当前路由的路径，才认为当前路由处于激活状态

匹配算法：
- 如果路由索引以`/`开头，严格匹配`Router.instance.currentRouteLocation.path === to.index`，模糊匹配`Router.instance.currentRouteLocation.fullPath.startsWith(to.index)`
- 如果路由索引不以`/`开头，则会匹配`Router.instance.currentRouteLocation.matched[i].name`，仅支持严格匹配

#### disabled

`disabled`属性用于禁用路由链接，当设置为`true`时，点击链接不会触发导航。

#### callback

`callback`属性用于设置导航回调函数，在导航完成后会被调用。

```ts
interface NavigateResult {
  // 导航状态
  status: NavigateStatus
  // 状态描述
  message: string
  // 最终的导航数据
  to: ReadonlyRouteLocation
  // 导航完成前的路由数据
  from: ReadonlyRouteLocation
  // 如果在守卫过程中被重定向，则为最初的路由目标
  redirectFrom: RouteTarget | undefined
  // 捕获到的异常
  error?: unknown
}
```

#### style

`style`属性用于设置`<a>`标签的样式。

#### class

`class`属性用于设置`<a>`标签的CSS类名。

### target

`target`属性用于设置`<a>`标签的`target`属性，仅http或https外部链接支持此属性。

可选值：`'_blank'`、`'_self'`、`'_parent'`、`'_top'`

### draggable

`draggable`属性用于设置`<a>`标签是否可拖拽，默认为`false`。

### children

`children`属性用于设置链接的内容，可以是字符串、元素或元素数组。如果不设置，则默认使用路由的索引作为内容。

## 编程式导航

除了使用`RouterLink`组件外，你还可以通过编程式导航来实现路由跳转。

### 获取路由器实例

使用`useRouter()`函数获取路由器实例：

```ts
import { useRouter } from '@vitarx/router'

const router = useRouter()
```

### 导航方法

路由器实例提供了以下导航方法：

#### push

导航到一个新的路由，会向历史记录添加一个新的记录。

```ts
// 路由目标对象
router.push({ index: '/home', hash: '#top' })

// 命名路由
router.push('home')

// 路由路径
router.push('/home')

// 带回调函数
router.push('/home', (result) => {
  if (result.status === 'success') {
    console.log('导航成功')
  }
})
```

#### replace

导航到一个新的路由，但会替换当前的历史记录。

```ts
// 路由目标对象
router.replace({ index: '/home', hash: '#top' })

// 命名路由
router.replace('home')

// 路由路径
router.replace('/home')
```

#### go

在历史记录中前进或后退指定步数。

```ts
// 后退一步
router.go(-1)

// 前进一步
router.go(1)
```

#### back

后退一步，相当于`router.go(-1)`。

```ts
router.back()
```

#### forward

前一步，相当于`router.go(1)`。

```ts
router.forward()
```

### navigate

`navigate`方法是push和replace的聚合方法，它仅接受一个`RouteTarget`对象：

```ts
router.navigate({
  index: '/home',
  isReplace: true // 设置为true可以替换当前路由
})
```

### 导航回调

所有导航方法都支持传入回调函数，在导航完成后被调用：

```ts
router.push('/home', (result) => {
  if (result.status === 'success') {
    console.log('导航成功')
  } else if (result.status === 'aborted') {
    console.log('导航被中止：', result.message)
  } else if (result.status === 'error') {
    console.error('导航出错：', result.error)
  }
})
```

### 导航目标

与Vue Router不同，VitaRx Router的导航目标使用`RouteTarget`接口定义：

```ts
interface RouteTarget {
  // 路由索引，/开头为路径，否则为名称
  index: RouteIndex
  // URL hash
  hash?: HashStr
  // URL 查询参数
  query?: Record<string, string>
  // 路由参数
  params?: Record<string, any>
  // 是否替换当前路由，仅在调用`router.navigate`时才生效，默认为`false`
  isReplace?: boolean
}
```

## 导航结果

导航结果包含导航状态和相关信息，用于描述导航的执行结果。

### 导航状态

导航状态是一个枚举值，表示导航的最终状态：

- `success`：导航成功，成功跳转到目标路由
- `aborted`：导航被阻止，通常是由导航守卫阻止导航
- `cancelled`：导航被取消，正在等待中间件处理结果时又触发了新的导航请求
- `duplicated`：重复导航，导航的目标和当前路由相同
- `not_matched`：路由未匹配，没有找到匹配的路由记录
- `exception`：捕获到异常，导航过程中发生了异常

### 导航结果接口

导航结果接口包含了导航的详细信息：

```ts
interface NavigateResult {
  // 导航状态
  status: NavigateStatus
  // 状态描述
  message: string
  // 最终的导航数据
  to: ReadonlyRouteLocation
  // 导航完成前的路由数据
  from: ReadonlyRouteLocation
  // 如果在守卫过程中被重定向，则为最初的路由目标
  redirectFrom: RouteTarget | undefined
  // 捕获到的异常
  error?: unknown
}
```

- `status`：导航状态，表示导航的最终状态
- `message`：状态描述，用于描述导航状态的具体原因
- `to`：最终的导航数据，表示导航完成后的路由数据
- `from`：导航完成前的路由数据，表示导航开始时的路由数据
- `redirectFrom`：如果在守卫过程中被重定向，则为最初的路由目标
- `error`：如果导航过程中捕获到异常，则包含异常信息

## 与 `VueRouter` 主要区别
- 使用`index`来统一表示路由目标，而不是`path`或`name`
- 路由参数使用`params`对象传递，不需要在路径中使用动态参数
- 增加了`isReplace`选项，用于指定是否替换当前路由
