# 快速上手

欢迎来到 Vitarx 文档！本章节将带您快速了解 Vitarx 的基本使用。

## 学习路径

本章节设计了一条循序渐进的学习路径，从环境搭建到复杂交互，帮助你全面掌握 Vitarx 的基础知识。无论你是前端新手还是有经验的开发者，都能通过这些步骤快速上手 Vitarx。

你将会通过本章节学习到：

1. [如何安装 Vitarx](/docs/quick-start/instance.html) - 了解不同的安装方式和项目初始化
2. [如何创建应用](/docs/quick-start/create-app.html) - 创建你的第一个 Vitarx 应用实例
3. [如何编写组件](/docs/quick-start/widget.html) - 掌握组件的基本结构和生命周期
4. [如何添加样式](/docs/quick-start/style.html) - 为你的组件添加样式，打造精美界面
5. [如何更新界面视图](/docs/quick-start/reactive.html) - 学习 Vitarx 的响应式系统，实现数据驱动的界面
6. [如何使用条件渲染](/docs/quick-start/conditional.html) - 根据条件动态显示或隐藏内容
7. [如何响应事件](/docs/quick-start/events.html) - 处理用户交互，实现交互式应用
8. [如何渲染列表](/docs/quick-start/list-rendering.html) - 高效渲染数据列表，优化性能

## 准备好了吗？

完成本章节的学习后，你将具备使用 Vitarx 构建现代化 Web 应用的基本能力。如果你想深入了解更多高级特性，可以继续阅读[深入组件](/docs/widget)章节。

让我们开始 Vitarx 的学习之旅吧！
