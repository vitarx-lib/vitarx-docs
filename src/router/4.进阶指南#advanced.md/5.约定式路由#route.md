# 约定式路由

我们可以通过约定固定的页面组件存放路径规则来生成路由，从而简化路由配置。

## 简单的约定式路由

假设约定在项目的src/pages目录下，每个页面组件都以index.tsx结尾，那么我们可以通过以下代码生成路由：

```ts
// src/router/index.ts

import type { LazyLoadWidget } from 'vitarx'
import { defineRoute } from 'vitarx-router'

// 使用 import.meta.glob 生成路由，注意路径！
const pages = import.meta.glob('../pages/**/index.tsx')
const routes = Object.entries(pages).map(([path, importWidget]) => {
  const name = path.split('/').at(-2)
  return defineRoute({
    path: `/${name === 'Home' ? '' : name}`,
    name,
    widget: importWidget as LazyLoadWidget
  })
})

export default routes
```

## 需要定义meta

如果需要定义meta，那么我们可以给每个页面组件都定义一个page.js文件，在文件中导出一个对象：

```ts
export default {
  title: 'Home'
}
```

然后使用import.meta.glob生成路由的时候，扫描page.js文件：

```ts
const pages = import.meta.glob('../pages/**/page.js', { eager: true,import: 'default' })

const widgets = import.meta.glob('../pages/**/index.tsx')
const routes = Object.entries(pages).map(([path, meta]) => {
  const widgetPath = path.replace('page.js', 'index.tsx')
  const name = path.split('/').at(-2)
  return defineRoute({
    path: `/${name === 'Home' ? '' : name}`,
    name,
    widget: widgets[widgetPath] as LazyLoadWidget,
    meta
  })
})

export default routes
```

## import.meta.glob 详解

`import.meta.glob` 是 Vite 提供的一个特殊的导入函数，用于批量导入文件。它接受一个 glob 模式字符串和一个可选的配置对象作为参数。

### Glob 匹配模式

glob 模式支持以下特殊字符：
- `*` - 匹配任意字符，不包括路径分隔符
- `**` - 匹配零个或多个层级的目录
- `?` - 匹配任意单个字符
- `{}` - 允许使用逗号分隔的列表

示例：
```ts
// 匹配 src/pages 下所有 .tsx 文件
import.meta.glob('../pages/**/*.tsx')

// 匹配多个文件类型
import.meta.glob('../pages/**/*.{js,jsx,ts,tsx}')

// 排除某些文件
import.meta.glob(['../pages/**/*.tsx', '!../pages/internal/**'])
```

### 配置选项

`import.meta.glob` 支持第二个参数来配置导入行为：

```ts
// 直接导入模块（同步），而不是返回动态导入函数
const modules = import.meta.glob('./dir/*.js', { eager: true })

// 只导入特定导出
const modules = import.meta.glob('./dir/*.js', { import: 'setup' })

// 自定义查询参数
const modules = import.meta.glob('./dir/*.js', { query: { custom: 'data' } })
```

这种方式可以让我们充分利用 TypeScript 的类型检查，确保路由配置的正确性。
