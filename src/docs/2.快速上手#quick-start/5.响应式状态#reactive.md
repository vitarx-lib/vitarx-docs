# 响应式状态

在 Vitarx 项目中你只需要通过 `ref` 、 `reactive` 等 [响应式API]() 来实现响应式状态；响应式状态被更新时，视图也会随之更新。


## 声明一个响应式状态

### ref()

我们可以通过 `ref()` 来声明一个响应式状态，它返回一个 `Ref` 对象，该对象有一个 `.value` 属性，用来访问和修改响应式状态的值。

```js
const count = ref(0)

console.log(count) // { value: 0 }
console.log(count.value) // 0

count.value++
console.log(count.value) // 1
```

> TS类型参考：[为ref指定类型]()

### reactive()

`reactive()` 可以用来声明一个响应式对象，它返回一个 `Proxy` 对象，该对象可以像普通对象一样访问和修改响应式对象的属性。

它具有以下局限性：

1. **只支持对象类型**：它只能用于对象类型(`对象{}`、`数组[]`、`Map`，`Set`等对象类型，特殊对象`null`除外)
2. **不能替换整个对象**：不能通过赋值的方式替换整个对象，这也就意味着我们不能轻易地“替换”响应式对象。
    ```js
    let state = reactive({ count: 0 })
    // 上面的 ({ count: 0 }) 引用将不再被追踪
    // (响应性连接已丢失！)
    state = reactive({ count: 1 })
    ```
   
由于以上限制，如果你需要随时替换整个响应式对象，那么你应该使用 `ref({})` 声明。

## 需注意的解构细节

### reactive中嵌套ref

如果你解构`Reactive`对象中的属性，且此属性的值不是一个`Reactive`对象，则会丢失响应性。

```js
const state = reactive({
  count:0
})
let { count } = state
// 不会影响到state.count，不会触发监听器
count++
```

如果在`Reactive`对象中嵌套`Ref`值代理对象会在读取时自动解构：

```js
const count = ref(0)
const state = reactive({
  count
})
console.log(count) // { value:0 }
// 读取时自动解构，无需 .value
console.log(state.count) // 0

state.count = 1
// 修改时，也会自动更新
console.log(count.value) // 1


const data = shallowReactive({
   count: ref(0)
})
// 浅层代理不会解构
console.log(data.count) // { value: 0 }
```

注意：只有在深层次响应对象中才会发生 `Ref` 解包，浅层响应对象不会自动解构！


### 集合的注意事项

原生集合类型 (如 Map) 中的元素被访问时，它不会被解构：

```js
const map = reactive(new Map([['count', ref(0)]]))
// Map对象不会被自动解构，这里需要 .value
console.log(map.get('count').value) // 0
```

## 在模板中使用

如果将 `ref` 对象当做HTML元素属性值或 `children` 使用，可以不使用 `.value`。

⚠️ **注意**：传递给组件不会自动解构！

```jsx
function App() {
   const count = ref(0)
   const className = ref('test')
   const data = reactive({
      name: '计数器'
   })
   // 在模板中使用的响应式状态被更新时，会自动更新视图，无需任何额外操作。
   return <div class={className}>
      <p>{data.name}-{count}</p>
      <button onClick={() => count.value++}>点击+1</button>
   </div>
}
```
