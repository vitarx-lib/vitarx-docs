# reactive()

## 概述

`reactive()` 函数用于创建一个响应式对象，它会将一个普通对象转换为可观察的响应式对象。当响应式对象的属性发生变化时，所有依赖于这些属性的副作用（如渲染函数、计算属性、监听器等）都会自动更新。

```js
import { reactive } from 'vitarx'

const state = reactive({
  count: 0,
  user: {
    name: 'Alice',
    age: 25
  }
})

// 修改属性会触发依赖更新
state.count++
state.user.name = 'Bob'
```

## 类型定义

```ts
// 深层响应式（默认）
function reactive<T extends object>(target: T): Reactive<T>

// 显式指定深层响应式
function reactive<T extends object>(target: T, deep: true): Reactive<T>

// 浅层响应式
function reactive<T extends object>(target: T, deep: false): ShallowReactive<T>
```

## 深层响应式与浅层响应式

`reactive()` 默认创建深层响应式对象，这意味着对象的所有嵌套属性都会被转换为响应式的：

```js
const state = reactive({
  user: {
    profile: {
      address: {
        city: 'Shanghai'
      }
    }
  }
})

// 深层嵌套属性也是响应式的
state.user.profile.address.city = 'Beijing' // 会触发更新
```

如果只需要对象的顶层属性具有响应性，可以使用浅层响应式：

```js
const state = reactive({
  user: {
    name: 'Alice'
  }
}, false) // 设置 deep 参数为 false

state.user = { name: 'Bob' } // 会触发更新
state.user.name = 'Charlie' // 不会触发更新，因为 user 对象本身不是响应式的
```

也可以使用 `shallowReactive()` 函数创建浅层响应式对象：

```js
import { shallowReactive } from 'vitarx'

const state = shallowReactive({
  user: {
    name: 'Alice'
  }
})
```

## 响应式对象的特性

### 1. 自动解包嵌套的 ref

当 `ref` 对象作为 `reactive` 对象的属性被访问时，会自动解包：

```js
import { ref, reactive } from 'vitarx'

const count = ref(0)
const state = reactive({
  count
})

console.log(count.value) // 0
console.log(state.count) // 0，自动解包，无需使用 .value

// 修改 state.count 会同步更新 count.value
state.count = 1
console.log(count.value) // 1

// 修改 count.value 也会同步更新 state.count
count.value = 2
console.log(state.count) // 2
```

注意：只有在深层响应式对象中才会发生 ref 自动解包，浅层响应式对象不会自动解包：

```js
const count = ref(0)
const state = shallowReactive({
  count
})

console.log(state.count) // { value: 0 }，不会自动解包
```

### 2. 集合类型的响应式支持

`reactive()` 支持对 Map、Set、WeakMap、WeakSet 等集合类型进行响应式处理：

```js
const set = reactive(new Set([1, 2, 3]))
const map = reactive(new Map([['key', 'value']]))

// 这些操作都是响应式的
set.add(4)
map.set('newKey', 'newValue')
set.delete(1)
map.clear()
```

### 3. 解构会丢失响应性

当你解构一个响应式对象时，解构出的属性将失去响应性：

```js
const state = reactive({ count: 0 })

// 解构后，count 不再是响应式的
let { count } = state
count++ // 不会影响 state.count，不会触发更新
```

## 获取原始对象

如果需要获取响应式对象的原始对象，可以使用 `toRaw()` 或 `unReactive()` 函数：

```js
import { reactive, toRaw, unReactive } from 'vitarx'

const original = { count: 0 }
const state = reactive(original)

const raw1 = toRaw(state) // 获取原始对象
const raw2 = unReactive(state) // 同样可以获取原始对象

console.log(raw1 === original) // true
console.log(raw2 === original) // true
```

## 限制

1. `reactive()` 只能用于对象类型，不能用于原始类型（如字符串、数字、布尔值等）。对于原始类型，应使用 `ref()`。

2. 不能对冻结对象（使用 `Object.freeze()` 冻结的对象）创建响应式对象。

3. 不能对已经是响应式对象的对象再次创建响应式对象（会直接返回原响应式对象）。

4. 不能对值代理对象（如 `ref` 创建的对象）创建响应式对象。

## 最佳实践

1. 对于复杂的嵌套对象结构，使用 `reactive()` 创建深层响应式对象。

2. 对于简单的原始类型值，使用 `ref()`。

3. 当只需要对象顶层属性具有响应性时，使用 `shallowReactive()` 或 `reactive(obj, false)`。

4. 避免直接修改通过 `toRaw()` 获取的原始对象，这样不会触发响应式更新。
