# Observers

## 概述

Observers 是 `Vitarx` 的全局观察者管理器，用于管理所有响应式对象的监听器。它提供了一套完整的 API 来注册、触发和管理监听器，支持批量处理和微任务队列优化，是响应式系统的核心组件之一。

## 核心方法

### register()

注册一个监听器来观察响应式对象的变化。

```js
import { reactive, Observers } from 'vitarx'

const state = reactive({ count: 0 })

// 监听特定属性
Observers.register(state, (props, origin) => {
  console.log(`属性 ${props.join(', ')} 发生了变化`)
}, 'count')

// 监听所有变化
Observers.register(state, (props, origin) => {
  console.log(`发生变化的属性: ${props.join(', ')}`)
})
```

### registerProps()

同时监听多个属性的变化。

```js
import { reactive, Observers } from 'vitarx'

const user = reactive({ name: 'Alice', age: 25 })

// 监听多个属性
Observers.registerProps(user, ['name', 'age'], (props, origin) => {
  console.log(`属性 ${props.join(', ')} 发生了变化`)
})
```

### registers()

同时监听多个响应式对象的变化。

```js
import { reactive, Observers } from 'vitarx'

const user1 = reactive({ name: 'Alice' })
const user2 = reactive({ name: 'Bob' })

// 监听多个对象
Observers.registers([user1, user2], (props, origin) => {
  console.log(`对象 ${origin.name} 的属性 ${props.join(', ')} 发生了变化`)
})
```

### trigger()

使用 `trigger()` 方法可以手动触发响应式对象的监听器通知。

```js
import { reactive, Observers } from 'vitarx'

const state = reactive({ count: 0 })

Observers.register(state, (props, origin) => {
  console.log(`属性 ${props.join(', ')} 发生了变化`)
})

// 手动触发特定属性的监听器
Observers.trigger(state, ['count'])
// 输出: 属性 count 发生了变化

// 触发所有属性的监听器
Observers.trigger(state)
// 输出: 属性 count 发生了变化
```

### 批处理机制

Observers 默认采用批处理机制来优化性能。当多个属性在同一个微任务周期内发生变化时，监听器的回调函数只会被触发一次。

```js
import { reactive, Observers } from 'vitarx'

const state = reactive({ count: 0, name: 'VitaRx' })

// 批量处理示例
Observers.register(state, (props, origin) => {
  console.log(`变化的属性: ${props.join(', ')}`)
})

// 在同一个微任务中修改多个属性
state.count++
state.name = 'New Name'
// 只会触发一次回调，输出: 变化的属性: count, name
```

如果需要立即响应每个属性的变化，可以通过设置 `batch: false` 来禁用批处理：

```js
Observers.register(state, (props, origin) => {
  console.log(`变化的属性: ${props.join(', ')}`)
}, undefined, { batch: false })
```

### 监听器生命周期

监听器实例提供了销毁机制，可以通过 `destroy()` 方法来移除监听器：

```js
import { reactive, Observers } from 'vitarx'

const state = reactive({ count: 0 })

// 创建监听器
const listener = Observers.register(state, (props, origin) => {
  console.log(`属性 ${props.join(', ')} 发生了变化`)
})

// 当不再需要监听时，销毁监听器
listener.destroy()
```

## 最佳实践

1. **合理使用批处理**：默认的批处理机制可以有效减少不必要的回调触发，提高性能。只有在确实需要立即响应每个变化时才禁用批处理。

2. **及时清理监听器**：当不再需要监听时，记得调用 `destroy()` 方法清理监听器，避免内存泄漏。

3. **选择合适的注册方法**：
   - 使用 `register()` 监听单个对象的特定属性或所有变化
   - 使用 `registerProps()` 监听多个指定属性
   - 使用 `registers()` 监听多个对象的变化

4. **避免在回调中修改被监听的属性**：这可能会导致无限循环。如果确实需要修改，请确保有适当的条件限制。

## 高级用法

### 自定义回调处理

使用 `addNotBatchCallback()` 注册不进行批处理的回调函数，用于实现一些特殊的监听需求：

```js
import { reactive, Observers } from 'vitarx'

const state = reactive({ count: 0 })

// 注册不批处理的回调
const remove = Observers.addNotBatchCallback(state, (props, origin) => {
  console.log(`立即响应变化: ${props.join(', ')}`)
})

// 不再需要时移除回调
remove()
```


### 获取观察目标

使用 `getObserveTarget()` 获取代理对象的原始目标：

```js
import { reactive, Observers } from 'vitarx'

const state = reactive({ count: 0 })
const target = Observers.getObserveTarget(state)
```
